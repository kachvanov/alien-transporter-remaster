# Alien Transporter Remaster

Ремастер Flash-игры **Alien Transporter v1.3.0** (Anton Karlov, 2016) для macOS (Apple Silicon) и Windows 10 (x64): те же уровни и та же физика, плюс игра по локальной сети (LAN) и плавная картинка 60/120 Гц.

**Это личный проект для домашнего использования.** Оригинальная игра, её графика и звуки принадлежат Anton Karlov. Поэтому ассеты оригинала и готовые сборки (dmg, exe) нигде не публикуются и не выкладываются в открытый доступ: ни на GitHub, ни в облака с публичными ссылками. Передавайте сборки только друг другу.

> Пометка **[не проверено]** означает: по сборке это ещё не проверено руками на реальной машине (авторы писали эту инструкцию по настройкам сборки и по тестам на одном Маке). Если что-то не совпало, это нормально: пожалуйста, скажите, что именно.

## Что внутри сборки

Три готовых файла (папка `dist/` после сборки):

| Файл | Для чего |
|---|---|
| `Alien Transporter Remaster-0.1.0-arm64.dmg` | macOS на Apple Silicon (M1 и новее) |
| `Alien Transporter Remaster Setup 0.1.0.exe` | Windows 10 x64, установщик |
| `Alien Transporter Remaster 0.1.0.exe` | Windows 10 x64, portable (без установки, запускается из любой папки) |

Версия игры у обоих игроков по сети должна быть одинаковой (см. «Если не подключается»).

## Установка на Mac

1. Откройте `Alien Transporter Remaster-0.1.0-arm64.dmg`.
2. Перетащите **Alien Transporter Remaster** в папку **Applications** (Программы) и закройте окно dmg.
3. Запустите игру из Launchpad или из папки Applications двойным кликом.

Приложение подписано только «ad-hoc» подписью (платного сертификата разработчика Apple нет), поэтому:

- На самом Маке, где собрана игра, она запускается без вопросов.
- Если вы **скопировали** dmg или приложение с другого компьютера (AirDrop, флешка, облако) и macOS пишет, что приложение **«повреждено»** или не может быть проверено, откройте Terminal и выполните:

  ```bash
  xattr -cr "/Applications/Alien Transporter Remaster.app"
  ```

  Эта команда снимает с приложения пометку «скачано из интернета». Затем запустите игру снова. Если и это не помогло, один раз перепечатайте подпись:

  ```bash
  codesign --force --deep -s - "/Applications/Alien Transporter Remaster.app"
  ```

- При первой игре по сети macOS спросит про доступ к **локальной сети** (текст: «Alien Transporter uses the local network to find and join LAN games»). Нажмите «Разрешить». Если случайно отказали, см. «Если не подключается».

[не проверено руками: установка из dmg и запуск через Applications, запрос доступа к локальной сети, `xattr -cr` на другом Маке]

## Установка на Windows 10

Выберите один из двух способов.

**Установщик (`Alien Transporter Remaster Setup 0.1.0.exe`):** запустите, выберите папку (можно оставить по умолчанию), нажмите «Установить». Ярлыки на рабочем столе и в меню «Пуск» создаются.

**Portable (`Alien Transporter Remaster 0.1.0.exe`):** положите файл куда угодно и запустите двойным кликом, устанавливать ничего не нужно.

Сборка не подписана сертификатом, поэтому Windows покажет синее окно **SmartScreen** («Windows защитила ваш компьютер»). Нажмите **«Подробнее» → «Выполнить в любом случае»**.

Когда вы впервые нажмёте Online → Host game, Защитник Windows (Defender Firewall) спросит про доступ. Отметьте галочку **«Частные сети»** и нажмите «Разрешить доступ» (подробнее в разделе про сеть).

В сборке для Windows нет самого крупного набора картинок (3x, он нужен только для 4K-мониторов). Поэтому на экране 4K, если картинка не появилась, запустите игру с флагом `--tier=2x` (ярлык → Свойства → Объект: после пути к exe добавьте пробел и `--tier=2x`). Для остальных экранов ничего делать не нужно.

[не проверено руками: установка и запуск на Windows 10, вид окна SmartScreen, запрос Defender Firewall, F3-счётчик в рамках бюджета на ноутбуке с 8 ГБ]

## Управление

| Действие | Клавиши |
|---|---|
| Игрок 1 (P1) | стрелки: ↑ газ, ← и → поворот |
| Игрок 2 (P2) | W газ, A и D поворот |
| Пауза | **P** или **Esc** |
| Полный экран | **F11** (также Alt+Enter; на Mac ещё Ctrl+Cmd+F) |
| Настройки ремастера | **F2** (режим «Classic 35 fps» без сглаживания до частоты монитора, набор картинок: auto / 1x / 2x / 3x; смена набора картинок вступает в силу после перезапуска) |
| Счётчик производительности | **F3** (FPS, время тика, трафик, сеть) |

Клавиши P1 и P2 меняются в игре, в **Garage** (экран выбора и настройки корабля). Сохраняется при выходе из Garage кнопками Play и Back (как в оригинале).

## Вдвоём на одном компьютере

Игрок 1 начинает уровень как обычно. Чтобы подключить второго игрока, **во время уровня второй игрок нажимает W** (газ P2): второй корабль входит в игру. Дальше он летит на W / A / D, а первый на стрелках.

## По сети (как в Minecraft)

Играют двое: хост (Player 1) и клиент (Player 2). Нужно:

- оба компьютера в **одной Wi-Fi** (или одной проводной сети);
- на обоих **одна и та же версия** игры (например, 0.1.0);
- Mac и Windows могут играть друг с другом в любом сочетании.

Шаги:

1. **Хост:** главное меню → **Online** → **Host Game**. Игра покажет «YOUR ADDRESSES», список адресов вида `192.168.x.x:47020`. Можно нажать **TEST**: игра проверит, что слушает порт на сетевых адресах (`OK` у каждого).
2. **Клиент:** главное меню → **Online** → **Join Game**. Хост появится в списке сам (обычно за 1–2 секунды): выберите его стрелками и нажмите **Connect**. Если списка нет, введите адрес хоста с экрана Host руками (например, `192.168.0.5`, порт 47020 по умолчанию) и нажмите **Connect**.
3. **Хост** нажимает **START** и выбирает уровень, как в обычной игре.
4. **Клиент** входит в уровень газом (на клиенте работают обе раскладки сразу: стрелки и W / A / D). Корабль второго игрока появится в игре хоста.
5. Пауза с клиента (P) ставит и снимает паузу на хосте; Esc на клиенте открывает вопрос «выйти из игры?». Если клиент закрыл окно или потерял сеть, хост продолжает играть, на экране будет «PLAYER 2 DISCONNECTED». Если закрыть игру на хосте, у клиента появится сообщение и возврат в меню.

Что известно про качество: на одном Маке (два экземпляра игры) отклик ввода клиента около 90 мс, трафик около 100 КБ/с, потери кадров не замечены. Это проверка на одном компьютере; на двух разных машинах по Wi-Fi **[не проверено]**.

## Если не подключается

Сначала проверьте самое простое:

- Обе машины в **одной** Wi-Fi-сети (не одна в основной, другая в «гостевой»). **Гостевые сети и общественные Wi-Fi часто блокируют связь между устройствами** («изоляция клиентов», AP isolation). Если так, подключитесь к основной сети или включите точку доступа на телефоне, а компьютер соединяйте с ней.
- **Версия игры одинакова** у обоих. В списке Join несовпадающая версия подписана «DIFFERENT VERSION», подключиться к такой игре нельзя.
- Если в списке нет игры, но подключение вручную по адресу работает, значит, блокируется автопоиск (UDP, порт 47021). Играть можно, вводя адрес руками.

### Windows (хост или клиент)

1. Сеть должна быть **Частной**: Параметры → Сеть и Интернет → Wi-Fi → свойства вашей сети → «Профиль сети» → **Частные**. Для «Общедоступной» сети Windows прячет компьютер от других.
2. Брандмауэр должен разрешать игру в **Частных сетях**. Если при первом Host Game вы отказали, окно больше не появится: Параметры → Безопасность Windows → Брандмауэр и защита сети → «Разрешить работу с приложением через брандмауэр» → найдите Alien Transporter Remaster (для portable: Electron) → поставьте галочку **Частная**.
3. Проверка порта с Windows на хост (подставьте IP хоста):

   ```powershell
   Test-NetConnection 192.168.0.5 -Port 47020
   ```

   В ответе должно быть `TcpTestSucceeded : True`. Если `False` при запущенном Host Game: фаервол, профиль сети или изоляция клиентов в роутере.

### Mac (хост или клиент)

1. Системные настройки → Конфиденциальность и безопасность → **Локальная сеть** → включите переключатель для **Alien Transporter Remaster**. Без него игра не видит соседей и не может подключиться.
2. Если включён фаервол macOS (Системные настройки → Сеть → Брандмауэр), при первом Host Game нажмите **«Разрешить входящие подключения»** (Allow). Если отказали, добавьте приложение в параметрах брандмауэра вручную.
3. Проверка порта с Mac на хост (подставьте IP хоста):

   ```bash
   nc -vz 192.168.0.5 47020
   ```

   Ответ «succeeded» означает, что порт открыт.

Кнопка TEST на экране Host проверяет только, что игра слушает на сетевых адресах. Блокировку фаерволом чужих машин она **не** показывает: для этого используйте `Test-NetConnection` или `nc` со второй машины.

[не проверено: все шаги этого раздела на Windows и на двух разных машинах; проверка Mac ↔ Windows по Wi-Fi ещё не проводилась; подробная пошаговая инструкция для проверки: `docs/06-lan-testing.md` §4]

## Где лежат сохранения

| ОС | Папка |
|---|---|
| macOS | `~/Library/Application Support/Alien Transporter Remaster/` |
| Windows | `%APPDATA%\Alien Transporter Remaster\` |

(На Windows откройте её так: Win+R → `%APPDATA%\Alien Transporter Remaster` → Enter. На Mac: Finder → «Переход» → «Переход к папке» (Cmd+Shift+G) → вставьте путь.)

В папке два файла:

- `save.json`: **прогресс игры** (пройденные уровни, купленные корабли и их настройки, выбранные клавиши);
- `settings.json`: настройки ремастера (F2) и положение окна.

**Как сбросить прогресс:** закройте игру и удалите `save.json` (лучше сначала скопируйте его куда-нибудь на память). При следующем запуске игра начнёт с нуля. Чтобы сбросить и настройки окна, удалите также `settings.json`. Если файл прогресса окажется повреждён, игра переименует его в `save.corrupt-<время>.json` и начнёт заново: старый файл остаётся рядом.

Прогресс сохраняется как в оригинале: при выходе из Garage (Play или Back), а не после каждого уровня.

## Для разработчика

- Правила проекта и архитектура: [`CLAUDE.md`](CLAUDE.md) и папка [`docs/`](docs/) (начните с `docs/00-overview.md` и `docs/ROADMAP.md`). Исходный код оригинала в декомпилированном виде лежит в `reference/as3/` (не публикуется).
- Нужны: Node.js 22 или новее, Java 17 и ffmpeg (для извлечения ассетов), файл оригинала `.swf` (Alien Transporter 1.3.0).
- Сборка с нуля:

  ```bash
  npm ci                      # зависимости (только в чистой папке; в рабочем клоне с общим node_modules не запускать)
  cp .env.example .env        # и впишите в ORIGINAL_SWF реальный путь к .swf оригинала
  npm run extract             # SWF → reference/ и assets/ (нужны Java 17 и ffmpeg)
  npm run dev                 # запуск в режиме разработки
  npm run check               # tsc + eslint + vitest
  npm run build:mac           # dmg, macOS arm64 (dist/)
  npm run build:win           # NSIS-установщик и portable, Windows x64 (dist/)
  ```

  Установщик Windows собирается с Mac (на Apple Silicon для `makensis` нужен Rosetta 2).
- В git не попадают `assets/`, `build/`, `reference/`, `vendor/original/`, `vendor/jpexs/`: это сгенерированное и принадлежащее автору оригинала.
- Проверка сети между машинами: `docs/06-lan-testing.md`; чек-листы сборок: `docs/05-verification.md` §10.
