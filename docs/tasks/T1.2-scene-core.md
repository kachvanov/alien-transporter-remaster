# T1.2 — Сцена Anthill-TS, AntG, ввод, AssetRegistry

**Милстоун:** M1 · **Зависит от:** T1.1, T0.4 · **Параллельно с:** T1.3 · **Размер:** L

## Цель
Портировать ядро Anthill без рисования: дерево сущностей (AntBasic/AntEntity/AntActor), анимации по метаданным manifest, камеру, тайлмапы уровней, состояние (AntState), глобальный `AntG`, клавиатуру и мышь поверх снимка ввода. Плюс реестр ассетов, который работает в воркере и в Node.

## Шаги
1. `src/engine/assets/AssetRegistry.ts`:
   - загрузка `manifest.json` и данных через абстракцию `AssetSource` (`fetch` в воркере, `fs` в Node);
   - API `getAnimation(symbolName) → { frames: FrameMeta[] }`, где `FrameMeta { texId, size1x, origin1x, trim1x, mask? }`;
   - `getLevel(n)`, `getModels()`, `getFont(name)`, `getEffects()`, `getMissions()`, `getTexts()`, `getSounds()`.
2. `src/engine/core/`:
   - `AntBasic`, `AntEntity` (1:1, включая `recycle(Class)`, `getAvailable/getAlive/getDead`, `sort`, `callAll/setAll`, velocity/drag/`moves`, `hitTest`, события, `scrollFactor`, `DEPTH_ID`, `NUM_OF_ACTIVE`);
   - `AntActor` — анимации из `AssetRegistry`: `addAnimationFromCache(name, key?, switchNow?)`, `switchAnimation`, `play/stop/gotoAndStop/gotoAndPlay/playRandomFrame/nextFrame/prevFrame`, `updateAnimation` 1:1. **Кадры 1-based**: `currentFrame ∈ [1, totalFrames]`, текущая текстура = `frames[roundFrame(currentFrame) − 1]`. `width/height/origin` — из `size1x`/`origin1x` текущего кадра. Поля `blend`, `color`, `alpha`, `smoothing`;
   - `AntAnimation` — метаданные;
   - `AntCamera` — `scroll`, `shake`, `follow` 1:1 (`Math.random` → `AntMath.random`); буфера нет;
   - `AntTileMap` — `setTileSize/setMapSize/addClip(symbolName)/cacheClips()` (сразу `eventProcess(1)` и `eventComplete` в том же порядке, что в оригинале), `setScrollFactor`, `drawQuickly`. Хранит `symbolName` слоя;
   - `AntMask` — не нужен игре (проверить grep-ом), не портировать;
   - `AntState` — `preUpdate/update/postUpdate`, `add/remove`;
   - `AntG` — статический класс: `elapsed`, `maxElapsed`, `timeScale`, `fixedElapsed`, `simTimeMs`, `keys: AntKeyboard`, `mouse: AntMouse`, `plugins: AntPluginManager`, `sounds` (заглушка до T1.8 `STUB(T1.8)`), `cameras`, `getCamera()`, `switchState(state)`, `updateInput(snapshot)`. Убрать `AntGStub` из T1.1.
3. `src/engine/input/`:
   - `keyCodes.ts`: таблица `event.code` → Flash keyCode (ASCII-коды для букв и цифр, стрелки 37–40, Space 32, Enter 13, Esc 27, Shift 16 и т.д. — ровно те, что есть в `AntKeyboard.addKey`);
   - `InputSnapshot { keysDown: number[], mouseX, mouseY, mouseDown, wheelDelta }`;
   - `AntKeyboard` 1:1: имена клавиш, `isDown/isPressed/isReleased` (Pressed/Released — фронты между снимками), `eventDown/eventUp`;
   - `AntMouse`/`AntMouseButton` 1:1 поверх снимка.
4. `src/engine/core/Anthill.ts` — тонкий класс с методом `tick(snapshot)` по порядку `01` §3. Шаги 3 (точка рендера) и 4 (плагины) вызываются через колбэки, чтобы `FrameWriter` (T1.5) встроился без изменений здесь.
5. Тесты:
   - AntEntity: глобальные координаты вложенных сущностей с углами и масштабом (эталон считать вручную по формулам из AS3), `recycle`, `kill/revive`;
   - AntActor: `play` при `animationSpeed` 0.5/1/2, `repeat` true/false, `reverse`, `animComplete` вызывается в правильный тик;
   - AntKeyboard: `isPressed` только в первом тике нажатия;
   - AntCamera: `shake` затухает за заданное время при фиксированном сиде.

## Выходы
`src/engine/{assets,core,input}/**`, тесты.

## Критерии приёмки
- [ ] Всё с шапками `// Port of …`, int-семантика по `int-report`.
- [ ] `AssetRegistry` грузит реальный `assets/manifest.json` в Node-тесте, `getAnimation("Coin_mc").frames.length === 30`.
- [ ] Тесты зелёные; `npm run check` зелёный. Коммит `T1.2: scene core`.

## Подводные камни
- `AntEntity` — 1183 строки. Не выкидывай «ненужное» (события, bounds, vertices): игра может это использовать. Непортированным остаётся только рисование (`draw`, `drawActor`, буферы, `BitmapData`).
- `x/y/angle` — `Number` (дефолт NaN) в объявлении, но в конструкторе они инициализируются. Смотри конструктор.
- Во Flash углы в градусах, в Box2D — в радианах. `AntEntity.angle` в градусах.
