# T1.2 — Anthill-TS scene, AntG, input, AssetRegistry

**Milestone:** M1 · **Depends on:** T1.1, T0.4 · **In parallel with:** T1.3 · **Size:** L

## Goal
Port the Anthill core without drawing: the entity tree (AntBasic/AntEntity/AntActor), animations driven by manifest metadata, the camera, level tile maps, state (AntState), the global `AntG`, keyboard and mouse on top of an input snapshot. Plus an asset registry that works in the worker and in Node.

## Read before starting
- `docs/01-architecture.md` §3 (loop), §4 (engine), §8 (input); `docs/04-porting-guide.md`
- `reference/as3/ru/antkarlov/anthill/{AntBasic,AntEntity,AntActor,AntAnimation,AntCamera,AntTileMap,AntMask,AntState,AntG,AntKeyboard,AntMouse,AntMouseButton,AntStorage,Anthill}.as`

## Steps
1. `src/engine/assets/AssetRegistry.ts`:
   - load `manifest.json` and data through an `AssetSource` abstraction (`fetch` in the worker, `fs` in Node);
   - API `getAnimation(symbolName) → { frames: FrameMeta[] }`, where `FrameMeta { texId, size1x, origin1x, trim1x, mask? }`;
   - `getLevel(n)`, `getModels()`, `getFont(name)`, `getEffects()`, `getMissions()`, `getTexts()`, `getSounds()`.
2. `src/engine/core/`:
   - `AntBasic`, `AntEntity` (1:1, including `recycle(Class)`, `getAvailable/getAlive/getDead`, `sort`, `callAll/setAll`, velocity/drag/`moves`, `hitTest`, events, `scrollFactor`, `DEPTH_ID`, `NUM_OF_ACTIVE`);
   - `AntActor` — animations from `AssetRegistry`: `addAnimationFromCache(name, key?, switchNow?)`, `switchAnimation`, `play/stop/gotoAndStop/gotoAndPlay/playRandomFrame/nextFrame/prevFrame`, `updateAnimation` 1:1. **Frames are 1-based**: `currentFrame ∈ [1, totalFrames]`, the current texture = `frames[roundFrame(currentFrame) − 1]`. `width/height/origin` come from `size1x`/`origin1x` of the current frame. Fields `blend`, `color`, `alpha`, `smoothing`;
   - `AntAnimation` — metadata;
   - `AntCamera` — `scroll`, `shake`, `follow` 1:1 (`Math.random` → `AntMath.random`); no buffer;
   - `AntTileMap` — `setTileSize/setMapSize/addClip(symbolName)/cacheClips()` (immediately `eventProcess(1)` and `eventComplete`, in the same order as in the original), `setScrollFactor`, `drawQuickly`. Stores the layer's `symbolName`;
   - `AntMask` — not needed by the game (verify with grep), do not port;
   - `AntState` — `preUpdate/update/postUpdate`, `add/remove`;
   - `AntG` — a static class: `elapsed`, `maxElapsed`, `timeScale`, `fixedElapsed`, `simTimeMs`, `keys: AntKeyboard`, `mouse: AntMouse`, `plugins: AntPluginManager`, `sounds` (stub until T1.8, `STUB(T1.8)`), `cameras`, `getCamera()`, `switchState(state)`, `updateInput(snapshot)`. Remove the `AntGStub` from T1.1.
3. `src/engine/input/`:
   - `keyCodes.ts`: a table `event.code` → Flash keyCode (ASCII codes for letters and digits, arrows 37–40, Space 32, Enter 13, Esc 27, Shift 16, etc. — exactly those present in `AntKeyboard.addKey`);
   - `InputSnapshot { keysDown: number[], mouseX, mouseY, mouseDown, wheelDelta }`;
   - `AntKeyboard` 1:1: key names, `isDown/isPressed/isReleased` (Pressed/Released are edges between snapshots), `eventDown/eventUp`;
   - `AntMouse`/`AntMouseButton` 1:1 on top of the snapshot.
4. `src/engine/core/Anthill.ts` — a thin class with a `tick(snapshot)` method in the order of `01` §3. Steps 3 (render point) and 4 (plugins) are invoked via callbacks so that `FrameWriter` (T1.5) plugs in without changes here.
5. Tests:
   - AntEntity: global coordinates of nested entities with angles and scale (compute the reference by hand from the AS3 formulas), `recycle`, `kill/revive`;
   - AntActor: `play` at `animationSpeed` 0.5/1/2, `repeat` true/false, `reverse`, `animComplete` is called on the right tick;
   - AntKeyboard: `isPressed` only on the first tick of the press;
   - AntCamera: `shake` decays within the given time at a fixed seed.

## Outputs
`src/engine/{assets,core,input}/**`, tests.

## Acceptance criteria
- [ ] Everything has `// Port of …` headers, int semantics checked with `int-report`.
- [ ] `AssetRegistry` loads the real `assets/manifest.json` in a Node test, `getAnimation("Coin_mc").frames.length === 30`.
- [ ] Tests are green; `npm run check` is green. Commit `T1.2: scene core`.

## Pitfalls
- `AntEntity` is 1183 lines. Do not drop the "unneeded" parts (events, bounds, vertices): the game may use them. Only drawing (`draw`, `drawActor`, buffers, `BitmapData`) stays unported.
- `x/y/angle` are `Number` (default NaN) in the declaration, but they are initialized in the constructor. Look at the constructor.
- In Flash, angles are in degrees; in Box2D they are in radians. `AntEntity.angle` is in degrees.
