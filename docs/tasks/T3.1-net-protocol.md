# T3.1 — `net/protocol`: handshake, input, коды ошибок

**Милстоун:** M3 · **Зависит от:** T1.5 · **Параллельно с:** M2, T3.2, T3.3, T3.5 · **Размер:** S

## Цель
Типизированный протокол (без транспорта), общий для main-процесса хоста и renderer'а клиента.

## Прочитать перед началом
- `docs/03-frame-and-network-protocol.md` §2–§5

## Шаги
1. `src/net/protocol.ts` (чистый TS, без DOM и Node):
   - `PROTO_VERSION = 1`, `DEFAULT_TCP_PORT = 47020`, `DEFAULT_UDP_PORT = 47021`;
   - zod-схемы и типы JSON-сообщений: `Hello`, `Welcome`, `Reject` (`full|version|busy`), `Notice`, `Bye`;
   - `encodeInput({seq, bits}) → ArrayBuffer(6)`, `decodeInput`; биты `GAS=1, LEFT=2, RIGHT=4, PAUSE_REQ=8`;
   - `messageKind(data)`: `'json' | 'frame' | 'input' | 'unknown'` (по типу данных и первому байту);
   - коды закрытия: `4000 full`, `4001 version`, `4002 busy`, `4003 protocol_error`;
   - `parseAddress("192.168.1.5:47020")` → `{host, port}` (IPv4, порт по умолчанию, валидация).
2. Тесты: round-trip ввода; невалидный JSON или схема → ошибка; `parseAddress` на граничных вводах (`"192.168.1.5"`, `":80"`, `"abc"`, `"300.1.1.1"`).

## Выходы
`src/net/protocol.ts`, тесты.
