# T3.1 — `net/protocol`: handshake, input, error codes

**Milestone:** M3 · **Depends on:** T1.5 · **In parallel with:** M2, T3.2, T3.3, T3.5 · **Size:** S

## Goal
A typed protocol (without transport), shared by the host's main process and the client's renderer.

## Read before starting
- `docs/03-frame-and-network-protocol.md` §2–§5

## Steps
1. `src/net/protocol.ts` (pure TS, no DOM or Node):
   - `PROTO_VERSION = 1`, `DEFAULT_TCP_PORT = 47020`, `DEFAULT_UDP_PORT = 47021`;
   - zod schemas and types for the JSON messages: `Hello`, `Welcome`, `Reject` (`full|version|busy`), `Notice`, `Bye`;
   - `encodeInput({seq, bits}) → ArrayBuffer(6)`, `decodeInput`; bits `GAS=1, LEFT=2, RIGHT=4, PAUSE_REQ=8`;
   - `messageKind(data)`: `'json' | 'frame' | 'input' | 'unknown'` (by data type and first byte);
   - close codes: `4000 full`, `4001 version`, `4002 busy`, `4003 protocol_error`;
   - `parseAddress("192.168.1.5:47020")` → `{host, port}` (IPv4, default port, validation).
2. Tests: input round-trip; invalid JSON or schema → error; `parseAddress` on edge-case inputs (`"192.168.1.5"`, `":80"`, `"abc"`, `"300.1.1.1"`).

## Outputs
`src/net/protocol.ts`, tests.
