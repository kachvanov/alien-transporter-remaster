# T3.2 — Хост: ws-сервер в main, MessagePort-мост воркер ↔ main, heartbeat

**Милстоун:** M3 · **Зависит от:** T3.1, T1.7 · **Параллельно с:** T3.3, T3.5 · **Размер:** M

## Цель
Хост принимает одного клиента по WebSocket, проверяет версию, пересылает ему кадры симуляции и отдаёт в воркер его ввод. Renderer в этом трафике не участвует.

## Прочитать перед началом
- `docs/01-architecture.md` §1 (сетевой путь хоста), §9; `docs/03-frame-and-network-protocol.md` §2–§5

## Шаги
1. `electron/net/wsServer.ts` — класс `HostServer` **без зависимостей от Electron**, чтобы тестировать в Node:
   - `start(port)`, `stop()`;
   - `onClientJoined(info)`, `onClientLeft(reason)`, `onInput(bits, seq)`, `sendFrame(buf)`;
   - один слот: второй клиент получает `reject: full` и close 4000;
   - `buildHash` сверяется (`reject: version`, 4001);
   - `ws.ping()` раз в 1 с, таймаут 5 с;
   - `perMessageDeflate: false`;
   - если сокет не успевает (`bufferedAmount > 1 МБ`), кадр пропускается — очередь не копится.
2. `electron/main.ts`: IPC `net:hostStart/Stop`. При старте создаётся `MessageChannelMain`: `port1` остаётся в main (кадры из воркера → `sendFrame`, ввод клиента → `port1.postMessage`), `port2` уходит в renderer (`webContents.postMessage('sim-port', null, [port2])`).
3. Preload: `ipcRenderer.on('sim-port', e => window.postMessage('sim-port', '*', e.ports))`. `src/app` ловит порт и передаёт воркеру (`worker.postMessage({t:'simPort'}, [port])`).
4. Воркер: если есть `simPort` и режим Host — после каждого тика `simPort.postMessage(frame.slice(0))`. Копия нужна, потому что оригинал уходит в renderer transfer'ом. Входящие `{bits, seq}` → `InputRouter.setRemote(bits)` (T1.6).
5. События хоста (клиент подключился или ушёл, ошибки) → renderer (`net.onHostEvent`) → воркер (для T3.6).
6. Тесты (Node): поднять `HostServer`, подключить `ws`-клиента → `welcome`; неверный `buildHash` → 4001; второй клиент → 4000; кадр доходит байт в байт; ввод приходит в `onInput` с `seq`; «молчащий» клиент отключается по таймауту (фейковые таймеры).

## Выходы
`electron/net/wsServer.ts`, правки `electron/{main,preload}.ts`, `src/app/*`, `src/sim/worker.ts`, тесты.

## Критерии приёмки
- [ ] Node-тесты зелёные.
- [ ] Вручную: `npm run dev` → dev-команда «host start». `websocat ws://127.0.0.1:47020` (или тестовый скрипт) после `hello` получает бинарные кадры ~35/с.
- [ ] `npm run check` зелёный. Коммит `T3.2: host server`.

## Подводные камни
- `MessagePortMain` в main и `MessagePort` в воркере — разные API (`port.on('message')` против `onmessage`). Не забудь `port.start()` в main.
- Слушать `0.0.0.0`, иначе с другой машины не подключиться.
