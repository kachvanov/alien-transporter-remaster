# T0.5 — Sounds → OGG + `sounds.json`

**Milestone:** M0 · **Depends on:** T0.3 · **In parallel with:** T0.4, T0.6 · **Size:** S

## Goal
The `sounds` step: the 55 named sounds of the original (52 SFX and 3 music tracks) → `assets/sfx/*.ogg` with exact length and seamless loops. Plus `assets/sounds.json`.

## Read before starting
- `docs/02-extraction-pipeline.md` (step 5)
- `reference/as3/ru/alientransporter/Sounds.as`, `Music.as`, `MusicManager.as`, `reference/as3/ru/antkarlov/anthill/AntSound.as` — to understand which sounds are played in a loop

## Steps
1. `-export sound build/extract/sounds` → match the files against `symbols.json` by id (`kind: "sound"`).
2. Name: `ru.alientransporter.Sounds_SndHitBox01` → `SndHitBox01`, `Music_SndMusicMenu01` → `SndMusicMenu01`.
3. ffmpeg: decode to PCM float, trim to exactly `sampleCount`, keep the original sample rate and channel count, encode with `libvorbis -q:a 6` → `assets/sfx/<Name>.ogg`.
4. Determine the list of loops from the code: where `AntSound` or `Sound.play` are called with repetition (`loops`, `repeat`, `9999`, `int.MAX_VALUE`) and where MusicManager plays music. Record it in `tools/extract/sound-loops.json` with a comment referencing the code line.
5. For loops: RMS of the first and last 20 ms, with a report. If there is silence at the start (< −60 dBFS) from MP3 padding — cut it off and record `trimStartSamples`.
6. `assets/sounds.json`: an array sorted by name; `id` = index; fields `name, file, loop, rate, channels, samples, trimStartSamples`.
7. Test: 55 entries, all files exist, the duration of each OGG (via `ffprobe`) matches `samples/rate` ±5 ms.

## Outputs
`tools/extract/{sounds.ts,sound-loops.json,sounds.test.ts}`, `assets/sfx/*.ogg`, `assets/sounds.json`.

## Acceptance criteria
- [ ] The test from step 7 is green.
- [ ] The report contains the list of loops and the results of the seam check.
- [ ] Manual check: `ffplay -loop 5 assets/sfx/SndEngineGas.ogg` (and the other loops) — no clicks or gaps at the seam. The result is recorded in the report.
- [ ] `npm run check` is green. Commit `T0.5: sounds`.

## Pitfalls
- 7 of the 62 SWF sounds have no class (timeline sounds of the preloader and intro) — skip them.
- Do not resample 11 kHz mono sounds. Web Audio resamples them itself on playback.
