# T0.5 — Звуки → OGG + `sounds.json`

**Милстоун:** M0 · **Зависит от:** T0.3 · **Параллельно с:** T0.4, T0.6 · **Размер:** S

## Цель
Шаг `sounds`: 55 именованных звуков оригинала (52 SFX и 3 музыкальных трека) → `assets/sfx/*.ogg` с точной длиной и бесшовными лупами. Плюс `assets/sounds.json`.

## Прочитать перед началом
- `docs/02-extraction-pipeline.md` (шаг 5)
- `reference/as3/ru/alientransporter/Sounds.as`, `Music.as`, `MusicManager.as`, `reference/as3/ru/antkarlov/anthill/AntSound.as` — понять, какие звуки играются в цикле

## Шаги
1. `-export sound build/extract/sounds` → сопоставить файлы с `symbols.json` по id (`kind: "sound"`).
2. Имя: `ru.alientransporter.Sounds_SndHitBox01` → `SndHitBox01`, `Music_SndMusicMenu01` → `SndMusicMenu01`.
3. ffmpeg: декод в PCM float, обрезка ровно до `sampleCount`, сохранение исходной частоты и числа каналов, кодирование `libvorbis -q:a 6` → `assets/sfx/<Name>.ogg`.
4. Список лупов определить по коду: где `AntSound` или `Sound.play` вызываются с повтором (`loops`, `repeat`, `9999`, `int.MAX_VALUE`) и где MusicManager проигрывает музыку. Зафиксировать в `tools/extract/sound-loops.json` с комментарием-ссылкой на строку кода.
5. Для лупов: RMS первых и последних 20 мс, отчёт. Если в начале есть тишина (< −60 dBFS) из MP3-паддинга — срезать её и записать `trimStartSamples`.
6. `assets/sounds.json`: массив, отсортированный по имени; `id` = индекс; поля `name, file, loop, rate, channels, samples, trimStartSamples`.
7. Тест: 55 записей, все файлы существуют, длительность каждого OGG (через `ffprobe`) совпадает с `samples/rate` ±5 мс.

## Выходы
`tools/extract/{sounds.ts,sound-loops.json,sounds.test.ts}`, `assets/sfx/*.ogg`, `assets/sounds.json`.

## Критерии приёмки
- [ ] Тест из шага 7 зелёный.
- [ ] Отчёт содержит список лупов и результаты проверки стыков.
- [ ] Ручная проверка: `ffplay -loop 5 assets/sfx/SndEngineGas.ogg` (и другие лупы) — без щелчков и пауз на стыке. Результат записан в отчёт.
- [ ] `npm run check` зелёный. Коммит `T0.5: sounds`.

## Подводные камни
- 7 из 62 звуков SWF без класса (звуки таймлайна прелоадера и интро) — пропускаем.
- 11 кГц моно звуки не ресемплировать. Web Audio сам ресемплирует при воспроизведении.
