# T2.7 — Missions, content and unlocks, music, pause, Casual/Hardcore

**Milestone:** M2 · **Depends on:** T2.6 · **Size:** M (~900 lines of AS3)

## Goal
19 quest missions with rewards, the content unlock system (ships, colors, features such as the magnet), menu and gameplay music with track selection as in the original, a pause with all its toggles, the Casual/Hardcore modes.

## Read before starting
- `reference/as3/ru/alientransporter/missions/*`: `MissionManager` (183), `MissionData` (102), `ContentManager` (160), `ContentData` (42); `assets/data/missions.json`
- `MusicManager.as` (170), `Music.as`, `Sounds.as`; `ui/{MissionBarUIView,MissionPopupView,PausePopupView}.as`

## Steps
1. `missions/` — 1:1 on top of JSON (`04` §5). `ContentManager.isUnlocked("featureMagnet")` and the other keys — as in the original.
2. `MusicManager` — 1:1: a random menu or game track via `AntMath`, volume, mute, crossfade. The result → `musicTrack/musicVol/muteFlags` in the `Frame`. Remove `STUB(T2.7)` from T1.8.
3. Pause: the Effects (`fancyEffects`), Quality, Music, Sound toggles — 1:1. Quality (`fancyQuality`) in the original enables `smoothing` of raster frames. For us this is texture filtering: on change the worker sends the renderer a message `{t:'quality', smooth}`, and the renderer switches `source.scaleMode` on all atlases (`linear`/`nearest`). We do not change the `Frame` format. In a network game the client uses its own local value.
4. Casual/Hardcore — check that the garage toggle affects `ShuttleStats` (T1.9a) and is saved.
5. Tests: completing the "deliver N passengers" mission via `GoalSystem`/`MissionManager` events → the reward is granted; `isUnlocked` after a purchase; MusicManager picks a track deterministically at a fixed seed.

## Outputs
`src/game/missions/**`, `src/game/MusicManager.ts`, `Music.ts`, `Sounds.ts`, UI and renderer changes (Quality), tests.

## Acceptance criteria
- [ ] Missions are visible in the interface, can be completed and give rewards. Music plays in the menu and in the game, the pause toggles work.
- [ ] `npm run check` is green. Commit `T2.7: missions, music, pause`.

## Pitfalls
- Quality in the original turned off smoothing of raster frames for speed. For us it is always `linear` by default. The toggle can stay functional (`nearest` = a "retro look"): it is harmless, and it is visible in the UI.
