# T2.7 — Миссии, контент и анлоки, музыка, пауза, Casual/Hardcore

**Милстоун:** M2 · **Зависит от:** T2.6 · **Размер:** M (~900 строк AS3)

## Цель
19 миссий-квестов с наградами, система анлоков контента (корабли, цвета, фичи вроде магнита), музыка меню и геймплея с выбором трека как в оригинале, пауза со всеми переключателями, режимы Casual/Hardcore.

## Прочитать перед началом
- `reference/as3/ru/alientransporter/missions/*`: `MissionManager` (183), `MissionData` (102), `ContentManager` (160), `ContentData` (42); `assets/data/missions.json`
- `MusicManager.as` (170), `Music.as`, `Sounds.as`; `ui/{MissionBarUIView,MissionPopupView,PausePopupView}.as`

## Шаги
1. `missions/` — 1:1 поверх JSON (`04` §5). `ContentManager.isUnlocked("featureMagnet")` и прочие ключи — как в оригинале.
2. `MusicManager` — 1:1: случайный трек меню или игры через `AntMath`, громкость, mute, кроссфейд. Результат → `musicTrack/musicVol/muteFlags` в `Frame`. Убрать `STUB(T2.7)` из T1.8.
3. Пауза: переключатели Effects (`fancyEffects`), Quality, Music, Sound — 1:1. Quality (`fancyQuality`) в оригинале включает `smoothing` растровых кадров. У нас это фильтрация текстур: при изменении воркер шлёт renderer'у сообщение `{t:'quality', smooth}`, и рендерер переключает `source.scaleMode` у всех атласов (`linear`/`nearest`). Формат `Frame` не меняем. В сетевой игре клиент использует своё локальное значение.
4. Casual/Hardcore — проверить, что переключатель гаража действует на `ShuttleStats` (T1.9a) и сохраняется.
5. Тесты: выполнение миссии «доставить N пассажиров» по событиям `GoalSystem`/`MissionManager` → награда начислена; `isUnlocked` после покупки; MusicManager выбирает трек детерминированно при фиксированном сиде.

## Выходы
`src/game/missions/**`, `src/game/MusicManager.ts`, `Music.ts`, `Sounds.ts`, правки UI и рендера (Quality), тесты.

## Критерии приёмки
- [ ] Миссии видны в интерфейсе, выполняются и дают награды. Музыка играет в меню и в игре, переключатели паузы работают.
- [ ] `npm run check` зелёный. Коммит `T2.7: missions, music, pause`.

## Подводные камни
- Quality в оригинале отключал сглаживание растровых кадров ради скорости. У нас по умолчанию всегда `linear`. Переключатель можно оставить рабочим (`nearest` = «ретро-вид»): это безобидно, и в UI он виден.
