# T2.3 — Эффекты частиц (AntEffect*) + StaticEffect

**Милстоун:** M2 · **Зависит от:** M1, T0.6 · **Параллельно с:** T2.1, T2.2, T2.4, T2.5 · **Размер:** M (~1.1K строк AS3)

## Цель
Все эффекты оригинала (взрывы, искры, вспышки, пыль, снег, магия портала, звёзды) воспроизводятся по данным `effects.json` тем же движком эмиттеров.

## Прочитать перед началом
- `reference/as3/ru/antkarlov/anthill/extensions/effects/*`: `AntEffectManager` (314), `AntEffectEmitter` (226), `AntEffectParticle` (163), `AntEffectProperty` (267), `AntEffectData` (88)
- `reference/data/effects.xml` и `assets/data/effects.json` (T0.6), `reference/as3/ru/alientransporter/states/PrepareState.as` (загрузка эффектов), `components/{StaticEffect,EffectInfo}.as`
- Все вызовы эффектов в игре: grep `AntEffectManager|AntEffectEmitter|effects\.` по `reference/as3/ru/alientransporter`

## Шаги
1. Порт 1:1 в `src/engine/effects/`. XML-разбор (E4X) заменить чтением JSON по конвенции `04` §5 (атрибуты — строки, приведение как в AS3-коде).
2. `AntEffectParticle` — AntActor. Анимации частиц — символы из `CacheList` (есть в manifest).
3. `StaticEffect` (компонент уровня, например `SnowFall_eff` в Level01) и `StaticEffectNode` + обработка в соответствующей системе.
4. Убрать все `STUB(T2.3)`.
5. Тесты: эмиттер `SnowFall_eff` за 35 тиков при фиксированном сиде создаёт эталонное число частиц; частица умирает по `lifeTime`; `AntEffectProperty` с диапазонами `lower/upper` использует `AntMath` (детерминированно).

## Выходы
`src/engine/effects/**`, правки систем, тесты.

## Критерии приёмки
- [ ] Level01 (снег), взрыв бочки (Level11), портал (конец любого уровня) визуально совпадают с Ruffle (описание и скриншоты в отчёте).
- [ ] `npm run check` зелёный. Коммит `T2.3: effects`.

## Подводные камни
- Проверь, какие эффекты зависят от `G.gameData.fancyEffects` (в оригинале это переключатель паузы «Effects»).
