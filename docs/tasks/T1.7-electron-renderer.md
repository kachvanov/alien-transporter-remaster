# T1.7 — Electron shell + Pixi-рендер: FramePlayer, letterbox, атласы, ввод

**Милстоун:** M1 · **Зависит от:** T1.5, T0.4 · **Параллельно с:** T1.6, T1.9a–b · **Размер:** L

## Цель
Рендерер, который умеет только одно: быстро и точно рисовать `Frame` с интерполяцией на частоте дисплея, в окне с правильным масштабированием 4:3. Плюс сбор ввода и оболочка Electron (окно, fullscreen, протокол ассетов, preload API).

## Прочитать перед началом
- `docs/01-architecture.md` §1, §5, §8, §9; `docs/03-frame-and-network-protocol.md` §1

## Шаги
1. **Main (`electron/main.ts`):**
   - протокол `app://assets/…` → файлы из `assets/` (dev: корень проекта; prod: `process.resourcesPath/assets`);
   - окно: 80% высоты рабочей области, 4:3, минимум 800×600, чёрный фон; позиция и размер сохраняются (временно в JSON в userData, T2.8 перенесёт в `settings.json`);
   - `--profile=N` → отдельный `userData`;
   - dev-флаги `--start-level=LevelNN`, `--tier=1x|2x|3x`, `--classic` пробрасываются в renderer.
2. **Preload (`electron/preload.ts`)** — `window.at` по `01` §9 (сейчас: `app.*`, `save.*` с заглушкой записи в `userData/save.json`, `settings.*`). Типы в `src/app/at.d.ts`.
3. **Renderer:**
   - `src/render/PixiRenderer.ts` — `Application` (`preference:'webgl'`, `antialias:false`, `resolution: devicePixelRatio`, `autoDensity:true`, `backgroundColor: 0x000000`), корневой контейнер 800×600 с letterbox-масштабом;
   - пул спрайтов по uid, `render(frame, alpha)`;
   - `AtlasLoader`: тир (авто: 3x, если `window.innerHeight × devicePixelRatio ≥ 1500` и тир есть в manifest; иначе 2x; флаг `--tier`), загрузка групп, выгрузка `level-NN` при смене `levelGroup`;
   - `Texture` на каждый texId лениво (`new Texture({ source: atlasSource, frame: rect })`);
   - anchor = `(origin1x − trim1x.xy) / trim1x.wh` (регистрационная точка относительно обрезанного прямоугольника), `scale = nodeScale / tierScale`;
   - `src/render/FramePlayer.ts` — очередь кадров, `alpha` по `01` §5, режим Classic, приём кадров из `SimClient` (T1.6) или из сети (T3.3);
   - `src/render/InputCollector.ts` — `keydown/keyup` по `event.code` → keyCode (таблица из T1.2), `preventDefault` для стрелок, пробела и Tab; pointer → логические координаты с учётом letterbox; blur окна → отпустить все клавиши;
   - горячие клавиши: F11 / Alt+Enter / ⌃⌘F — fullscreen; F3 — PerfOverlay (FPS, число узлов, байты кадра, `tickCost`, draw calls).
4. **Тестовая сцена до T1.9e:** в `GameLoop` временно создать сцену из нескольких AntActor (`Coin_mc`, `Shuttle01Body_mc`, слой `Level01BG_mc`) с движением. Визуально проверить интерполяцию и anchor.
5. Тесты: юнит на расчёт letterbox и anchor; FramePlayer: интерполяция позиции и угла (включая переход через ±π), teleport не интерполируется; e2e: окно, canvas не пустой, F11 переключает fullscreen.

## Выходы
`electron/{main,preload}.ts`, `src/app/**`, `src/render/**`, тесты.

## Критерии приёмки
- [ ] Тестовая сцена: монета вращается плавно на 120 Гц (MBP) и 60 Гц; с `--classic` — ступенчато на 35 fps.
- [ ] Масштаб: при растягивании окна и в fullscreen сохраняется 4:3, поля чёрные, картинка резкая (3x на Retina).
- [ ] Ассеты грузятся по `app://`, а не `file://`; в production-сборке (`npm run build`) тоже.
- [ ] `npm run check` и `npm run test:e2e` зелёные. Коммит `T1.7: renderer`.

## Подводные камни
- Pixi v8: `Texture.from` не подходит для кадров атласа. Создавай `new Texture({ source, frame: new Rectangle(...) })`.
- Не пересортировывай `children` каждый кадр без нужды: меняй порядок, только если он поменялся (сравни последовательность uid).
- `devicePixelRatio` меняется при переносе окна между мониторами — слушай `matchMedia` и пересоздавай resolution.
