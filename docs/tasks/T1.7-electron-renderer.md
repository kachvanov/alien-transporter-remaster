# T1.7 — Electron shell + Pixi render: FramePlayer, letterbox, atlases, input

**Milestone:** M1 · **Depends on:** T1.5, T0.4 · **In parallel with:** T1.6, T1.9a–b · **Size:** L

## Goal
A renderer that does only one thing: draw a `Frame` quickly and accurately, with interpolation at the display refresh rate, in a window with correct 4:3 scaling. Plus input collection and the Electron shell (window, fullscreen, asset protocol, preload API).

## Read before starting
- `docs/01-architecture.md` §1, §5, §8, §9; `docs/03-frame-and-network-protocol.md` §1

## Steps
1. **Main (`electron/main.ts`):**
   - protocol `app://assets/…` → files from `assets/` (dev: the project root; prod: `process.resourcesPath/assets`);
   - window: 80% of the work-area height, 4:3, minimum 800×600, black background; position and size are persisted (temporarily as JSON in userData, T2.8 will move them to `settings.json`);
   - `--profile=N` → a separate `userData`;
   - dev flags `--start-level=LevelNN`, `--tier=1x|2x|3x`, `--classic` are forwarded to the renderer.
2. **Preload (`electron/preload.ts`)** — `window.at` per `01` §9 (for now: `app.*`, `save.*` with a stub writing to `userData/save.json`, `settings.*`). Types in `src/app/at.d.ts`.
3. **Renderer:**
   - `src/render/PixiRenderer.ts` — `Application` (`preference:'webgl'`, `antialias:false`, `resolution: devicePixelRatio`, `autoDensity:true`, `backgroundColor: 0x000000`), a root container of 800×600 with letterbox scaling;
   - a sprite pool keyed by uid, `render(frame, alpha)`;
   - `AtlasLoader`: tier (auto: 3x if `window.innerHeight × devicePixelRatio ≥ 1500` and the tier is in the manifest; otherwise 2x; flag `--tier`), group loading, unloading `level-NN` when `levelGroup` changes;
   - a `Texture` per texId, lazily (`new Texture({ source: atlasSource, frame: rect })`);
   - anchor = `(origin1x − trim1x.xy) / trim1x.wh` (the registration point relative to the trimmed rectangle), `scale = nodeScale / tierScale`;
   - `src/render/FramePlayer.ts` — a frame queue, `alpha` per `01` §5, Classic mode, receiving frames from `SimClient` (T1.6) or from the network (T3.3);
   - `src/render/InputCollector.ts` — `keydown/keyup` by `event.code` → keyCode (table from T1.2), `preventDefault` for arrows, Space and Tab; pointer → logical coordinates accounting for the letterbox; window blur → release all keys;
   - hotkeys: F11 / Alt+Enter / ⌃⌘F — fullscreen; F3 — PerfOverlay (FPS, node count, frame bytes, `tickCost`, draw calls).
4. **Test scene until T1.9e:** in `GameLoop` temporarily create a scene of several AntActors (`Coin_mc`, `Shuttle01Body_mc`, the `Level01BG_mc` layer) with movement. Visually verify interpolation and anchor.
5. Tests: a unit test for the letterbox and anchor computation; FramePlayer: interpolation of position and angle (including crossing ±π), teleport is not interpolated; e2e: the window, the canvas is not empty, F11 toggles fullscreen.

## Outputs
`electron/{main,preload}.ts`, `src/app/**`, `src/render/**`, tests.

## Acceptance criteria
- [ ] Test scene: the coin rotates smoothly at 120 Hz (MBP) and 60 Hz; with `--classic` it moves in steps at 35 fps.
- [ ] Scaling: when the window is stretched and in fullscreen, 4:3 is preserved, the margins are black, the picture is sharp (3x on Retina).
- [ ] Assets load via `app://`, not `file://`; in the production build (`npm run build`) as well.
- [ ] `npm run check` and `npm run test:e2e` are green. Commit `T1.7: renderer`.

## Pitfalls
- Pixi v8: `Texture.from` is not suitable for atlas frames. Create `new Texture({ source, frame: new Rectangle(...) })`.
- Do not re-sort `children` every frame unnecessarily: change the order only if it has changed (compare the uid sequence).
- `devicePixelRatio` changes when the window is moved between monitors — listen to `matchMedia` and recreate the resolution.
