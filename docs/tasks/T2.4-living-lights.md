# T2.4 — Living lights: лучи сенсоров, касания, альфа-маски, рендер

**Милстоун:** M2 · **Зависит от:** M1, T0.4 (альфа-маски) · **Параллельно с:** T2.1–T2.3, T2.5 · **Размер:** M (~660 строк AS3 + рендер)

## Цель
Сенсоры-прожекторы работают как в оригинале: лучи останавливаются на пикселях шаттла, касание луча с шаттлом активирует сенсор и ракеты, свет рисуется радиальным градиентом.

## Шаги
1. `src/engine/lights/AntLightEnvironment.ts`:
   - вместо `_backendBuffer` (BitmapData) — `isOpaque(x, y)`;
   - для каждого «непрозрачного» ребёнка (и его детей, в порядке отрисовки): обратный глобальный трансформ точки → локальные координаты кадра → бит альфа-маски текущего кадра из `alphamasks.bin` (с учётом origin; вне маски — прозрачно);
   - `true`, если хотя бы один объект непрозрачен в этой точке;
   - `update()` / `updateLights` — 1:1.
2. `AntLight.ts` — 1:1. Логика из `draw()` (лучи с `rayStep`/`angleStep`, построение полигона, `eventBeginTouch`/`eventEndTouch` с координатами) выполняется в точке рендера (`01` §3). Результат — полигон, градиент (`_colors`, `_alphas`, `_ratio`, матрица → центр и радиус), `blur`, `blend` для `Frame` ext LIGHT.
3. `SensorView` — 1:1 (`colorIn`/`colorOut`, `alpha = 0.5`, `live`, шаги, `updateInterval = 0.1`).
4. FrameWriter: узел AntLight → `texId = 0xFFFF`, `hasExt`, LIGHT-payload.
5. Рендер `src/render/LightRenderer.ts`: `Graphics.poly(points).fill(FillGradient radial …)`, blend узла, `BlurFilter`, если `blur > 0`. Переиспользовать `Graphics` по uid.
6. Убрать `STUB(T2.4)` (включая временный геометрический тест в SensorSystem).
7. Тесты:
   - `isOpaque` для шаттла в известной позиции: центр корпуса → true, точка за пределами → false, пиксель прозрачной «дыры» кадра → false;
   - луч сенсора Level13 останавливается на шаттле, `eventBeginTouch` приходит в ожидаемый тик при скриптовом подлёте (эталон).

- [ ] `npm run check` зелёный. Коммит `T2.4: living lights`.

## Подводные камни
- В оригинале `isOpaque` принимает `int`-координаты (пиксели камеры 800×600). Приводи `|0`, как там.
- Шаттл — единственный непрозрачный объект, но реализация должна быть общей (любой AntActor в environment).
