# T0.1 — Repository scaffold

**Milestone:** M0 · **Depends on:** — · **In parallel with:** — · **Size:** M

## Goal
An empty but fully working Electron + TypeScript + Vite project. There is a window with a PixiJS canvas (black screen with the text "Alien Transporter Remaster — scaffold"), a Web Worker that sends a "ping" every 1000/35 ms, and a configured linter with layer boundaries, tests and scripts.

## Read before starting
- `CLAUDE.md`, `docs/00-overview.md`, `docs/01-architecture.md` (§2 structure, §9 Electron).

## Steps
1. The repository is already initialized (branch `main`), `.gitignore` already exists — extend it, do not rewrite it. You work in the orchestrator's worktree. `node_modules` may be a symlink to the main copy: a plain `npm install` is allowed, `npm ci` is not.
2. Initialize **electron-vite** (vanilla-ts template) in the project root (not in a subfolder). Three entry points: `electron/main.ts`, `electron/preload.ts`, `src/app/main.ts` (renderer, `index.html`).
3. Pin versions exactly (no `^`):
   - `electron` — latest stable (currently 44.x; Windows 10 is supported);
   - `electron-vite`, `vite`, `typescript` (5.x+), `pixi.js` (8.x), `ws`, `zod`;
   - dev: `vitest`, `@playwright/test`, `eslint`, `typescript-eslint`, `prettier`, `electron-builder`, `sharp`, `maxrects-packer`, `fast-xml-parser`, `pixelmatch`, `pngjs`, `tsx`.
   Record the chosen versions in the report.
4. `tsconfig`: `strict`, `noImplicitOverride`, `noUncheckedIndexedAccess`, `useDefineForClassFields: true`, `target: ES2022`, `moduleResolution: bundler`. Separate tsconfigs for `electron/` (node), `src/` (dom + webworker) and `tools/` (node). **Exclude everywhere** `.claude/**`, `reference/**`, `build/**`, `assets/**`, `vendor/**`, `out/**`, `dist/**`. The same goes for ESLint `ignores`, Vitest `exclude` and Playwright `testIgnore`: `.claude/worktrees/` holds copies of the project belonging to other agents; they must not be checked or tested.
5. Create the directories from `docs/01-architecture.md` §2 (with `.gitkeep`): `src/{engine,physics,game,frame,sim,render,audio,net,app}`, `electron/net`, `tools/extract`, `tests/{unit,golden,e2e,visual}`.
6. **ESLint (flat config)** with rules:
   - `no-restricted-imports` for `src/{engine,physics,game,frame,sim}/**`: forbid `pixi.js`, `electron`, `../render/*`, `../audio/*`, `../app/*`;
   - `no-restricted-globals` for the same paths: `window`, `document`, `AudioContext`, `requestAnimationFrame`, `localStorage`;
   - `no-restricted-properties`: `Math.random`, `Date.now`, `performance.now` in the same paths (except `src/sim/GameLoop.ts` and `src/sim/worker.ts`, where `performance.now` is allowed);
   - `src/{render,audio,app}/**`: `electron` is forbidden.
   Add a "trap" test: a temporary file with a violation must produce a linter error (check manually and describe in the report, then delete the file).
7. Scripts in `package.json`:
   ```
   dev            electron-vite dev
   build          electron-vite build
   check          tsc -p tsconfig.json --noEmit && tsc -p tsconfig.node.json --noEmit && eslint . && vitest run
   test           vitest
   test:e2e       playwright test
   extract        tsx tools/extract/index.ts
   viewer         vite --config tools/viewer/vite.config.ts   (stub until T0.8)
   build:mac      electron-vite build && electron-builder --mac --arm64
   build:win      electron-vite build && electron-builder --win --x64
   ```
8. Renderer: create a Pixi `Application` (`preference: 'webgl'`), black background, text in the center. Start a Web Worker (`src/sim/worker.ts`) via `new Worker(new URL(...), { type: 'module' })`; the worker sends `{type:'tick', n}` every 1000/35 ms, and the renderer shows the tick counter in the corner.
9. Main: `BrowserWindow` 1024×768, `backgroundColor '#000'`, `contextIsolation: true`, `sandbox: true`, `backgroundThrottling: false`. Register a privileged `app://` scheme (for future assets).
10. `.env.example`: `ORIGINAL_SWF=/Applications/Flash Games/AlienTransporter.swf`. Lookup order for the path in scripts: `process.env.ORIGINAL_SWF` (set in `.claude/settings.json`) → `.env` → default value.
11. Vitest: one example test in `tests/unit/sanity.test.ts`. Playwright: `tests/e2e/smoke.spec.ts` via `_electron.launch` — the window opened, the canvas contains non-black pixels (text), the tick counter grows.
12. `electron-builder.yml`: `appId: local.alientransporter.remaster`, `productName: Alien Transporter Remaster`, mac `target: dmg`, arch `arm64`, `identity: null`; win `target: [nsis, portable]`, arch `x64`; `directories: { buildResources: resources, output: dist }` (the `build/` folder is taken by the extraction pipeline and is in .gitignore); `extraResources`: `assets/**` (empty for now).

## Outputs
`package.json`, `package-lock.json`, `electron.vite.config.ts`, `tsconfig*.json`, `eslint.config.js`, `.prettierrc`, `.gitignore`, `.env.example`, `electron-builder.yml`, `electron/main.ts`, `electron/preload.ts`, `src/app/main.ts`, `index.html`, `src/sim/worker.ts`, `tests/unit/sanity.test.ts`, `tests/e2e/smoke.spec.ts`, `playwright.config.ts`, `vitest.config.ts`.

## Acceptance criteria
- [ ] `npm run dev` opens a window with text and a growing tick counter (~35/s).
- [ ] `npm run check` is green; a layer-boundary violation is caught (shown in the report).
- [ ] `npm run test:e2e` is green.
- [ ] All dependency versions are exact.
- [ ] Commit `T0.1: scaffold`.

## Pitfalls
- The root already contains `CLAUDE.md`, `docs/` and `tools/extract/java/SymbolInfo.java`. They must not be overwritten or deleted. Generate the electron-vite template into a temporary folder and move the files over manually.
- Worker in electron-vite: import via `new URL('./worker.ts', import.meta.url)` + `{ type: 'module' }`. Check that this works in `build` too, not only in `dev`.
- Do not set `sandbox: false`: a preload with `contextBridge` works in the sandbox as well.
- Do not commit `node_modules`, `assets`, `reference`.
