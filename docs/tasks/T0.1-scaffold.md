# T0.1 — Каркас репозитория

**Милстоун:** M0 · **Зависит от:** — · **Параллельно с:** — · **Размер:** M

## Цель
Пустой, но полностью рабочий проект Electron + TypeScript + Vite. Есть окно с canvas PixiJS (чёрный экран с надписью «Alien Transporter Remaster — scaffold»), Web Worker, который шлёт «пинг» каждые 1000/35 мс, настроены линтер с границами слоёв, тесты и скрипты.

## Прочитать перед началом
- `CLAUDE.md`, `docs/00-overview.md`, `docs/01-architecture.md` (§2 структура, §9 Electron).

## Шаги
1. Репозиторий уже инициализирован (ветка `main`), `.gitignore` уже есть — дополняй его, не переписывай. Ты работаешь в worktree оркестратора. `node_modules` может быть симлинком на основную копию: обычный `npm install` допустим, `npm ci` — нет.
2. Инициализировать **electron-vite** (шаблон vanilla-ts) в корне проекта (не в подпапке). Три входа: `electron/main.ts`, `electron/preload.ts`, `src/app/main.ts` (renderer, `index.html`).
3. Зафиксировать версии точно (без `^`):
   - `electron` — последняя стабильная (сейчас 44.x; Windows 10 поддерживается);
   - `electron-vite`, `vite`, `typescript` (5.x+), `pixi.js` (8.x), `ws`, `zod`;
   - dev: `vitest`, `@playwright/test`, `eslint`, `typescript-eslint`, `prettier`, `electron-builder`, `sharp`, `maxrects-packer`, `fast-xml-parser`, `pixelmatch`, `pngjs`, `tsx`.
   Запиши выбранные версии в отчёт.
4. `tsconfig`: `strict`, `noImplicitOverride`, `noUncheckedIndexedAccess`, `useDefineForClassFields: true`, `target: ES2022`, `moduleResolution: bundler`. Отдельные tsconfig для `electron/` (node), `src/` (dom + webworker) и `tools/` (node). **Везде исключить** `.claude/**`, `reference/**`, `build/**`, `assets/**`, `vendor/**`, `out/**`, `dist/**`. То же — в `ignores` ESLint, в `exclude` Vitest и в `testIgnore` Playwright: в `.claude/worktrees/` лежат копии проекта других агентов, их нельзя проверять и тестировать.
5. Создать каталоги из `docs/01-architecture.md` §2 (с `.gitkeep`): `src/{engine,physics,game,frame,sim,render,audio,net,app}`, `electron/net`, `tools/extract`, `tests/{unit,golden,e2e,visual}`.
6. **ESLint (flat config)** с правилами:
   - `no-restricted-imports` для `src/{engine,physics,game,frame,sim}/**`: запрещены `pixi.js`, `electron`, `../render/*`, `../audio/*`, `../app/*`;
   - `no-restricted-globals` для тех же путей: `window`, `document`, `AudioContext`, `requestAnimationFrame`, `localStorage`;
   - `no-restricted-properties`: `Math.random`, `Date.now`, `performance.now` в тех же путях (кроме `src/sim/GameLoop.ts` и `src/sim/worker.ts`, где `performance.now` разрешён);
   - `src/{render,audio,app}/**`: запрещён `electron`.
   Добавить тест-«ловушку»: временный файл с нарушением должен давать ошибку линтера (проверить вручную и описать в отчёте, файл удалить).
7. Скрипты в `package.json`:
   ```
   dev            electron-vite dev
   build          electron-vite build
   check          tsc -p tsconfig.json --noEmit && tsc -p tsconfig.node.json --noEmit && eslint . && vitest run
   test           vitest
   test:e2e       playwright test
   extract        tsx tools/extract/index.ts
   viewer         vite --config tools/viewer/vite.config.ts   (заглушка до T0.8)
   build:mac      electron-vite build && electron-builder --mac --arm64
   build:win      electron-vite build && electron-builder --win --x64
   ```
8. Renderer: создать Pixi `Application` (`preference: 'webgl'`), чёрный фон, текст по центру. Запустить Web Worker (`src/sim/worker.ts`) через `new Worker(new URL(...), { type: 'module' })`; воркер раз в 1000/35 мс шлёт `{type:'tick', n}`, а renderer выводит счётчик тиков в углу.
9. Main: `BrowserWindow` 1024×768, `backgroundColor '#000'`, `contextIsolation: true`, `sandbox: true`, `backgroundThrottling: false`. Регистрация привилегированной схемы `app://` (для будущих ассетов).
10. `.env.example`: `ORIGINAL_SWF=/Applications/Flash Games/AlienTransporter.swf`. Порядок поиска пути в скриптах: `process.env.ORIGINAL_SWF` (задан в `.claude/settings.json`) → `.env` → значение по умолчанию.
11. Vitest: один тест-пример в `tests/unit/sanity.test.ts`. Playwright: `tests/e2e/smoke.spec.ts` через `_electron.launch` — окно открылось, в canvas есть не-чёрные пиксели (текст), счётчик тиков растёт.
12. `electron-builder.yml`: `appId: local.alientransporter.remaster`, `productName: Alien Transporter Remaster`, mac `target: dmg`, arch `arm64`, `identity: null`; win `target: [nsis, portable]`, arch `x64`; `directories: { buildResources: resources, output: dist }` (папка `build/` занята пайплайном извлечения и в .gitignore); `extraResources`: `assets/**` (пока пусто).

## Подводные камни
- В корне уже лежат `CLAUDE.md`, `docs/` и `tools/extract/java/SymbolInfo.java`. Их нельзя перезаписать и удалить. Шаблон electron-vite генерируй во временную папку и переноси файлы вручную.
- Worker в electron-vite: импорт через `new URL('./worker.ts', import.meta.url)` + `{ type: 'module' }`. Проверь, что это работает и в `build`, а не только в `dev`.
- Не ставь `sandbox: false`: preload с `contextBridge` работает и в sandbox.
- Не коммить `node_modules`, `assets`, `reference`.
