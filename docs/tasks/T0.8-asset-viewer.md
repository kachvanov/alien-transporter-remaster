# T0.8 — Dev Asset Viewer

**Милстоун:** M0 · **Зависит от:** T0.4, T0.7 · **Параллельно с:** M1 (T1.1–T1.3) · **Размер:** M

## Цель
`npm run viewer` открывает в браузере dev-страницу (Vite + Pixi). На ней можно смотреть любую анимацию из manifest в любом тире с проигрыванием на 35 fps, и любой уровень — три слоя плюс оверлей объектов из `levelNN.json`. Это главный инструмент визуальной отладки ассетов для всех следующих задач.

## Прочитать перед началом
- `docs/02-extraction-pipeline.md` §4.5 (manifest), §7 (уровни)

## Шаги
1. `tools/viewer/` (отдельный Vite-конфиг; раздаёт `assets/` как статику).
2. Вкладка **Symbols**: список символов с поиском. Выбранный символ проигрывается на 35 fps (кнопки play/pause/step, выбор тира 1x/2x/3x, масштаб 1–4×). Регистрационная точка — перекрестие; bounding box — рамка. Показывать `size1x`, `origin1x`, число кадров.
3. Вкладка **Contact sheet**: сетка первых кадров всех символов группы.
4. Вкладка **Level**: выбор уровня 01–20; слои Back/BG/FG (галочки), оверлей объектов по классам (цвета как в T0.7), подсказка при наведении (`cls`, `alias`, props).
5. Использовать ту же zod-схему manifest, что и движок (`src/engine/assets/schemas.ts`).

## Выходы
`tools/viewer/**`, скрипт `viewer` в `package.json`.

## Критерии приёмки
- [ ] `Coin_mc` вращается плавно; перекрестие origin в центре монеты во всех тирах.
- [ ] `Shuttle01Body_mc` (5 кадров) и `PassengerBlue01Walk_mc` проигрываются без дёрганья кадра (origin стабилен).
- [ ] Level01: слои совпадают друг с другом, оверлей ground-объектов ложится на скалы.
- [ ] Скриншоты этих трёх проверок сохранены в `build/viewer-shots/` (пути в отчёте).
- [ ] `npm run check` зелёный. Коммит `T0.8: asset viewer`.
