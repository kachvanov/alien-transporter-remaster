# T0.2 — JPEXS и декомпиляция в `reference/`

**Милстоун:** M0 · **Зависит от:** T0.1 · **Параллельно с:** — · **Размер:** S

## Цель
`npm run extract -- --step=decompile` скачивает JPEXS, копирует SWF, декомпилирует AS3 в `reference/as3/`, раскладывает XML/PNG-данные в `reference/data/` и создаёт `build/extract/swf.xml`.

## Прочитать перед началом
- `docs/02-extraction-pipeline.md` (шаги 1–2)

## Шаги
1. `tools/extract/index.ts` — оркестратор шагов (`--step=<name>` или все по порядку), с кешем по хэшам входов в `build/extract/.cache.json`.
2. `tools/extract/get-jpexs.sh` (или `.ts`): скачать `ffdec_26.3.0.zip` (URL и SHA-256 в `02`), проверить хэш, распаковать в `vendor/jpexs/`. Если уже распакован — пропустить.
3. Путь к SWF: `process.env.ORIGINAL_SWF` → `.env` → `/Applications/Flash Games/AlienTransporter.swf`. Копирование SWF в `vendor/original/AlienTransporter.swf`. При первом запуске SHA-256 сохраняется в `tools/extract/swf.sha256` (этот файл коммитится), при следующих — сверяется.
4. `-export script,binaryData,symbolClass` → `build/extract/raw` → перенос:
   - `raw/scripts/**` → `reference/as3/**`;
   - `raw/binaryData/*` → `reference/data/` с именами из `02` §2 (сопоставление по имени класса в имени файла JPEXS, например `2220_ru.alientransporter.missions.MissionManager_XmlMissions.bin` → `missions.xml`);
   - `raw/symbolClass/*.csv` → `build/extract/symbolClass.csv`.
5. `-export image` → `build/extract/raw/images`. Нужны только картинки растровых шрифтов `ru.alientransporter.Fonts_ImgFont*`: сопоставить по SymbolClass и положить как `reference/data/fonts/font01.png`, `font04Blue.png` и т.д. Debug-картинки Anthill (`AntDrawer_ImgFont`, `AntSysButton_ImgButtons`) не нужны.
6. `-swf2xml vendor/original/AlienTransporter.swf build/extract/swf.xml` (для отладки; основные данные дают `SymbolInfo`).
7. Проверки (скрипт падает при нарушении):
   - в `reference/as3/ru/**` нет `§§`;
   - есть `reference/as3/ru/alientransporter/Config.as` с `FRAME_RATE:int = 35`;
   - есть 20 файлов `reference/as3/Level*Physic_mc.as`;
   - есть `missions.xml`, `texts_en.xml`, `effects.xml` и 10 пар шрифтов (xml + png).
8. Тест `tools/extract/decompile.test.ts` проверяет эти инварианты (пропускается, если `reference/` отсутствует — для CI без SWF).

## Выходы
`tools/extract/{index.ts,get-jpexs.sh,decompile.ts,decompile.test.ts,swf.sha256}`, заполненные `reference/as3/`, `reference/data/`.

## Критерии приёмки
- [ ] С чистого клона `npm run extract -- --step=decompile` отрабатывает за разумное время (JPEXS ~10–30 с).
- [ ] Повторный запуск ничего не пересобирает (кеш).
- [ ] Проверки из шага 7 зелёные.
- [ ] `npm run check` зелёный. Коммит `T0.2: decompile pipeline`.

## Подводные камни
- Java вызывай с `-Djava.awt.headless=true`, иначе на macOS появится иконка в Dock.
- JPEXS пишет прогресс в stdout. Сохраняй его в `build/extract/logs/*.log`, а в консоль выводи только сводку.
- `reference/` в `.gitignore` (авторские права), но агенты работают с ним локально.
