# T0.2 — JPEXS and decompilation into `reference/`

**Milestone:** M0 · **Depends on:** T0.1 · **In parallel with:** — · **Size:** S

## Goal
`npm run extract -- --step=decompile` downloads JPEXS, copies the SWF, decompiles AS3 into `reference/as3/`, lays out the XML/PNG data in `reference/data/` and creates `build/extract/swf.xml`.

## Read before starting
- `docs/02-extraction-pipeline.md` (steps 1–2)

## Steps
1. `tools/extract/index.ts` — the step orchestrator (`--step=<name>` or all in order), with a cache keyed by input hashes in `build/extract/.cache.json`.
2. `tools/extract/get-jpexs.sh` (or `.ts`): download `ffdec_26.3.0.zip` (URL and SHA-256 in `02`), verify the hash, unpack into `vendor/jpexs/`. If already unpacked — skip.
3. SWF path: `process.env.ORIGINAL_SWF` → `.env` → `/Applications/Flash Games/AlienTransporter.swf`. Copy the SWF to `vendor/original/AlienTransporter.swf`. On the first run the SHA-256 is saved to `tools/extract/swf.sha256` (this file is committed); on later runs it is compared against it.
4. `-export script,binaryData,symbolClass` → `build/extract/raw` → move:
   - `raw/scripts/**` → `reference/as3/**`;
   - `raw/binaryData/*` → `reference/data/` with the names from `02` §2 (matched by the class name in the JPEXS file name, e.g. `2220_ru.alientransporter.missions.MissionManager_XmlMissions.bin` → `missions.xml`);
   - `raw/symbolClass/*.csv` → `build/extract/symbolClass.csv`.
5. `-export image` → `build/extract/raw/images`. Only the bitmap-font images `ru.alientransporter.Fonts_ImgFont*` are needed: match them by SymbolClass and put them as `reference/data/fonts/font01.png`, `font04Blue.png`, etc. The Anthill debug images (`AntDrawer_ImgFont`, `AntSysButton_ImgButtons`) are not needed.
6. `-swf2xml vendor/original/AlienTransporter.swf build/extract/swf.xml` (for debugging; the main data comes from `SymbolInfo`).
7. Checks (the script fails on any violation):
   - there is no `§§` in `reference/as3/ru/**`;
   - `reference/as3/ru/alientransporter/Config.as` exists with `FRAME_RATE:int = 35`;
   - there are 20 files `reference/as3/Level*Physic_mc.as`;
   - `missions.xml`, `texts_en.xml`, `effects.xml` and 10 font pairs (xml + png) exist.
8. The test `tools/extract/decompile.test.ts` checks these invariants (skipped if `reference/` is absent — for CI without the SWF).

## Outputs
`tools/extract/{index.ts,get-jpexs.sh,decompile.ts,decompile.test.ts,swf.sha256}`, populated `reference/as3/`, `reference/data/`.

## Acceptance criteria
- [ ] From a clean clone, `npm run extract -- --step=decompile` completes in a reasonable time (JPEXS ~10–30 s).
- [ ] A repeated run rebuilds nothing (cache).
- [ ] The checks from step 7 are green.
- [ ] `npm run check` is green. Commit `T0.2: decompile pipeline`.

## Pitfalls
- Invoke Java with `-Djava.awt.headless=true`, otherwise an icon appears in the Dock on macOS.
- JPEXS writes progress to stdout. Save it to `build/extract/logs/*.log` and print only a summary to the console.
- `reference/` is in `.gitignore` (copyright), but agents work with it locally.
