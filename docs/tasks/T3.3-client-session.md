# T3.3 — Client: WebSocket, jitter buffer, input, disconnects, overlay

**Milestone:** M3 · **Depends on:** T3.1, T1.7 · **In parallel with:** T3.2, T3.5 · **Size:** M

## Goal
The client connects to the host by IP, smoothly displays its frames, sends its own key presses and handles a lost connection correctly.

## Read before starting
- `docs/03-frame-and-network-protocol.md` §2–§6, `docs/01-architecture.md` §1, §5

## Steps
1. `src/net/clientSession.ts` (renderer): `connect(host, port, hello)` → states `connecting → handshaking → playing → closed(reason)`, events for the UI.
2. **Jitter buffer** `src/net/JitterBuffer.ts` — pure logic without DOM, per `03` §6 (adaptive delay 1.5–3 ticks, reset on overflow). `FramePlayer` (T1.7) in client mode takes frames from the buffer according to the "playback clock".
3. Sound: `AudioEngine.apply(frame)` is called when a frame becomes current (do not lose or repeat oneShots — account for `tick`).
4. **Input:** `InputCollector` → bits (`gas/left/right` — the union of the P1 and P2 layouts from the local settings, `pauseReq` — the edge of P) → `encodeInput` on change + a 35 Hz heartbeat.
5. **Disconnects:** no frames for 3 s or a `close` → state `closed` with a reason → UI "Connection lost" → main menu (the navigation itself is in T3.4/T3.6).
6. **Esc on the client** — a local overlay (drawn by the renderer): "Disconnect? Yes / No". Yes → `{t:'bye'}` → close.
7. In client mode the local worker is not started (or is stopped).
8. Tests: `JitterBuffer` on synthetic arrivals (`05` §8); `clientSession` against the `HostServer` from T3.2 in Node (with `ws` standing in as `WebSocket` via injection) — handshake, frame reception, sending input, reaction to `reject`.

## Outputs
`src/net/{clientSession,JitterBuffer}.ts`, changes to `src/render/FramePlayer.ts`, `src/app/*`, `src/render/ClientOverlay.ts`, tests.

## Acceptance criteria
- [ ] Tests are green.
- [ ] Manually: two instances on one Mac (`--profile=2`), the client sees the host's world smoothly, and its input moves the (still test) P2 object (full integration is T3.6).
- [ ] `npm run check` is green. Commit `T3.3: client session`.

## Pitfalls
- `binaryType = 'arraybuffer'` is mandatory.
- Do not interpolate across `sceneReset` — after a screen change show the new frame immediately.
