# T2.6 — screens/, PrepareState, переходы; без спонсорских элементов

**Милстоун:** M2 · **Зависит от:** T2.5 · **Размер:** L (~2.7K строк AS3)

## Цель
Полный поток игры как в оригинале. Запуск → PrepareState (подготовка) → главное меню → выбор уровня → уровень → экран завершения (звёзды, статистика) → следующий уровень. Плюс гараж (корабли, цвета, переназначение клавиш, Casual/Hardcore), credits, рестарт.

## Прочитать перед началом
- `reference/as3/ru/alientransporter/screens/*`: `BasicScreen` (112), `MainMenuScreen` (76), `SelectLevelScreen` (413), `GameScreen` (310), `LevelCompleteScreen` (380), `RestartLevelScreen` (54), `GarageScreen` (618), `CreditsScreen` (66)
- `states/PrepareState.as` (207) — в оригинале там кеширование анимаций и эффектов с прогрессом
- `ui/FadeEffectView.as`

## Шаги
1. `PrepareState` — у нас кешировать нечего. Оставить последовательность инициализации (G.init, загрузка сохранения, регистрация эффектов) и сразу перейти в меню. `AntG.frameRate = 28` игнорировать (`04` §4). Экран загрузки не нужен, но если в оригинале есть логотип-заставка автора (не спонсора) — сохранить.
2. Экраны — 1:1. Переходы через `FadeEffectView` (обычная анимация, `01` §5).
3. **Удалить спонсорское**:
   - кнопки `BtnMoreGames_mc`, `BtnArmorGames_mc`, `BtnArmor_mc`, `BtnArmorLogoSmall_mc`, `BtnFaceBook_mc`, `BtnTwitter_mc`, `BtnPatreon_mc`;
   - интро `AGIntro_mc`;
   - всё, что вызывает API Armor Games (достижения и т.п.: grep `ArmorGames`/`agi`/`achievement` в `reference/as3`).
   Раскладку оставшихся кнопок не сдвигать (просто не создавать удалённые). Каждое удаление пометить `// DEVIATION: sponsor removed`. Кнопка `BtnAchievements_mc`: если она ведёт на сайт спонсора — удалить; если на внутренний экран — оставить.
4. **Credits** — оставить. Кнопки авторов (`BtnAnton_mc`, `BtnAhura_mc`, `BtnWesley_mc`) открывают ссылки через `hostApi.openExternal` (whitelist доменов — те URL, что в коде). Если URL мёртвый — оставить кнопку, ссылку отключить (`DEVIATION`).
5. **GarageScreen**: выбор корабля и цветов, покупка за монеты, переназначение клавиш P1/P2 (6 кнопок, `KeyInputPopupView`), переключатель Casual/Hardcore — 1:1. Новые клавиши сохраняются в настройки (T2.8), пока в `Config`.
6. `SelectLevelScreen`: 20 кнопок уровней (бонусные — `BtnLevelBonus_mc`), звёзды, блокировки.
7. Стартовый экран по умолчанию — главное меню. `--start-level` остаётся dev-флагом.
8. Убрать `STUB(T2.6)`.
9. e2e: меню → Play → выбор Level01 → уровень запущен → Esc/P → Main menu → Garage → смена цвета → Back.
