# T2.8 — Сохранения и настройки; Classic 35 fps; тир графики

**Милстоун:** M2 (завершающая) · **Зависит от:** T2.7 · **Размер:** M

## Цель
Прогресс и настройки надёжно сохраняются на диск и переживают перезапуск и сбой. Появился экран или раздел с настройками ремастера (то, чего нет в оригинале).

## Прочитать перед началом
- `docs/01-architecture.md` §7, §9; `reference/as3/ru/alientransporter/data/GameData.as` (`saveData/loadData/clearData/hasSaveData`)

## Шаги
1. `electron/save.ts`: `load(key)`/`write(key, data)` → `userData/<key>.json`, атомарно (`.tmp` + `rename`). Если файл битый — бэкап `*.corrupt-<ts>.json` и старт с чистого.
2. `WorkerSaveStorage` (T1.6) ↔ preload ↔ main. Предзагрузка `save.json` до `PrepareState`.
3. `settings.json`: клавиши P1/P2 (из Garage), `fancyEffects`, `fancyQuality`, `muteMusic`, `muteSounds` (если оригинал хранит их в `GameData` — оставить там, в settings не дублировать), `classic35` (bool), `tier` (`auto|1x|2x|3x`), окно (размер, позиция, fullscreen), `lastJoinAddress`, `netPort`.
4. **Настройки ремастера** (новое, минимально): в паузе или главном меню оригинала места нет, поэтому клавиша **F2** открывает системный оверлей в стиле UI игры (растровые шрифты, кнопки `BtnBasic_mc`) с пунктами «Smooth motion (60/120 Hz)», «Graphics: Auto/1x/2x/3x», «Fullscreen», «Network port». Оверлей рисуется рендерером поверх игры (не через симуляцию), клавиши в это время в игру не идут. Помечен как `DEVIATION: remaster settings`.
5. Тесты: `save.ts` (атомарность, битый файл); round-trip настроек; после перезапуска приложения (e2e: пройти уровень скриптом, перезапустить, проверить, что уровень 2 разблокирован).

## Выходы
`electron/save.ts`, `src/sim/WorkerSaveStorage.ts`, `src/app/settings.ts`, `src/render/RemasterSettingsOverlay.ts`, тесты.

## Критерии приёмки (= приёмка M2 вместе с остальными)
- [ ] Прогресс, покупки, клавиши и настройки переживают перезапуск. После `kill -9` посреди записи файл не битый.
- [ ] Приёмка M2 из `docs/ROADMAP.md` выполнена полностью (включая `grep -r "STUB(" src` — пусто).
- [ ] `npm run check` и `npm run test:e2e` зелёные. Коммит `T2.8: saves and settings`.
