# T2.8 — Saves and settings; Classic 35 fps; graphics tier

**Milestone:** M2 (closing task) · **Depends on:** T2.7 · **Size:** M

## Goal
Progress and settings are saved to disk reliably and survive a restart and a crash. A screen or section with the remaster's settings appears (something the original does not have).

## Read before starting
- `docs/01-architecture.md` §7, §9; `reference/as3/ru/alientransporter/data/GameData.as` (`saveData/loadData/clearData/hasSaveData`)

## Steps
1. `electron/save.ts`: `load(key)`/`write(key, data)` → `userData/<key>.json`, atomically (`.tmp` + `rename`). If the file is corrupt — back it up as `*.corrupt-<ts>.json` and start clean.
2. `WorkerSaveStorage` (T1.6) ↔ preload ↔ main. Preload `save.json` before `PrepareState`.
3. `settings.json`: P1/P2 keys (from the Garage), `fancyEffects`, `fancyQuality`, `muteMusic`, `muteSounds` (if the original stores them in `GameData` — leave them there, do not duplicate in settings), `classic35` (bool), `tier` (`auto|1x|2x|3x`), window (size, position, fullscreen), `lastJoinAddress`, `netPort`.
4. **Remaster settings** (new, minimal): there is no place for them in the original's pause or main menu, so the **F2** key opens a system overlay in the game's UI style (bitmap fonts, `BtnBasic_mc` buttons) with the items "Smooth motion (60/120 Hz)", "Graphics: Auto/1x/2x/3x", "Fullscreen", "Network port". The overlay is drawn by the renderer on top of the game (not through the simulation), and keys do not reach the game while it is open. Marked as `DEVIATION: remaster settings`.
5. Tests: `save.ts` (atomicity, corrupt file); settings round-trip; after an application restart (e2e: complete a level with a script, restart, check that level 2 is unlocked).

## Outputs
`electron/save.ts`, `src/sim/WorkerSaveStorage.ts`, `src/app/settings.ts`, `src/render/RemasterSettingsOverlay.ts`, tests.

## Acceptance criteria (= M2 acceptance together with the others)
- [ ] Progress, purchases, keys and settings survive a restart. After `kill -9` in the middle of a write the file is not corrupt.
- [ ] The M2 acceptance from `docs/ROADMAP.md` is fully met (including `grep -r "STUB(" src` — empty).
- [ ] `npm run check` and `npm run test:e2e` are green. Commit `T2.8: saves and settings`.

## Pitfalls
- Do not save to disk every tick. Write only when the original calls `saveData()` and when settings change (500 ms debounce).
