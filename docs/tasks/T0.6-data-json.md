# T0.6 — Шрифты, миссии, тексты, эффекты → JSON

**Милстоун:** M0 · **Зависит от:** T0.2 · **Параллельно с:** T0.3–T0.5 · **Размер:** M

## Цель
Шаг `data`: XML-данные оригинала → JSON в `assets/data/` с zod-схемами. Семантика и структура 1:1.

## Прочитать перед началом
- `docs/02-extraction-pipeline.md` (шаг 6), `docs/04-porting-guide.md` §5 (конвенция XML → JSON)
- `reference/data/*.xml`; потребители: `ru/alientransporter/fonts/Font.as`, `missions/MissionManager.as`, `missions/ContentManager.as`, `texts/Text.as`, `ru/antkarlov/anthill/extensions/effects/AntEffectManager.as`

## Шаги
1. Универсальный конвертер `xmlToJson` (fast-xml-parser) по конвенции `04` §5: атрибуты → поля, повторяющиеся дочерние → массивы, **все атрибуты остаются строками** (AS3-код сам делает `Number()`/`int()`). Комментарии отбрасываются. Порядок элементов сохраняется.
2. Шрифты: `fontXX.xml` → `assets/data/fonts/fontXX.json` `{ name, charInterval, chars: [{ name, x, y, w, h }] }`. Здесь числа приводятся к number: это наш формат, его читает порт `Font.as`. Закомментированные в XML символы не включать.
3. `missions.xml` → `missions.json`, `texts_en.xml` → `texts.json`, `effects.xml` → `effects.json` (универсальным конвертером).
4. zod-схемы в `src/engine/assets/schemas.ts`: `FontSchema`, `MissionsSchema`, `TextsSchema`, `EffectsSchema`. Схемы описывают фактическую структуру: сначала посмотри XML, потом пиши схему.
5. Тесты: 10 шрифтов; в `missions.json` 19 элементов `Mission`; в `effects.json` есть `CacheList` и список эффектов, включая `SnowFall_eff` (он используется в Level01 `StaticEffect_com`); валидация всех файлов схемами.

## Выходы
`tools/extract/{data.ts,xmlToJson.ts,data.test.ts}`, `assets/data/{fonts/*.json,missions.json,texts.json,effects.json}`, схемы.

## Критерии приёмки
- [ ] Тесты из шага 5 зелёные.
- [ ] В отчёте для каждого XML показан фрагмент исходника и результата (5–10 строк).
- [ ] `npm run check` зелёный. Коммит `T0.6: data json`.

## Подводные камни
- В `effects.xml` есть `PropertiesList` со ссылкой на `effects.swf` — это остаток редактора эффектов. Клипы эффектов лежат в основном SWF (их список — `CacheList`, он уходит в whitelist T0.4).
- `Text_XmlTextEN` ссылается на символы-картинки текста (`PauseTextEN_mc` и т.д.) — они тоже нужны в whitelist (проверь, что T0.4 их берёт).
