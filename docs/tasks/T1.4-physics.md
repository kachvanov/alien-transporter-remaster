# T1.4 — Физика: box2dweb + порт Box2D-for-Anthill + ModelManager

**Милстоун:** M1 · **Зависит от:** T1.2, T0.7 · **Параллельно с:** T1.5, T1.6 · **Размер:** L

## Цель
Box2D 2.1a (box2dweb) подключён как неизменяемый vendored-модуль с типами. Плагин Anthill для Box2D портирован 1:1: менеджер, тела, фигуры, суставы, контакты, флаги, модели. Модели тел строятся из `assets/data/models.json`.

## Прочитать перед началом
- `docs/00-overview.md` (параметры физики), `docs/04-porting-guide.md` §7
- `reference/as3/ru/antkarlov/anthill/plugins/box2d/**` (3528 строк): `AntBox2DManager`, `AntBox2DBody` (extends AntActor!), `AntBox2DContact`, `AntBox2DContactFilter`, `AntBox2DContactListener`, `AntBox2DFlag`, `AntBox2DFlagManager`, `shapes/*`, `joints/*`, `models/AntModelData`, `models/AntModelManager`. `AntBox2DDrawer` → вместо него debug-линии в `Frame`
- `reference/as3/Shuttle01Model_mc.as` (параметры фигур и суставов модели)

## Шаги
1. **Подключение:** зависимость `box2dweb` версии **ровно `2.1.0-b`**. Файл `node_modules/box2dweb/box2d.js` — 10 856 строк, CommonJS, в конце `module.exports = Box2D`, SHA-256 `b44dc71a5958089bcc1c53eb867754bdf73b97c093361e48cf72622e630addb8`. `src/physics/box2dweb/index.ts`: `import Box2D from 'box2dweb'` (CJS-interop Vite/esbuild и Vitest) и плоский реэкспорт классов (`export const b2World = Box2D.Dynamics.b2World` …). Тест сверяет SHA-256 файла в `node_modules` (защита от подмены или патчей). `patch-package` и правки запрещены.
2. `box2d.d.ts`: типы только для реально используемого API. Список собрать grep-ом по `b2[A-Z]\w*` и вызовам методов в `reference/as3/ru/**` и `plugins/box2d/**`.
3. Портировать `plugins/box2d/**` в `src/physics/anthill/` 1:1:
   - `AntBox2DManager`: `step = 1/40`, `velocityIterations = 6`, `positionIterations = 15`, `scale = 30`, gravity `(0, 9.81)`, `create()` → `start()` → `AntG.plugins.add(this)`. В `update()`: `Step` + `ClearForces`, если не `pause`;
   - `AntBox2DBody` наследует `AntActor` (из T1.2) и синхронизирует позицию и угол сущности с телом, как в оригинале;
   - остальное (фигуры, суставы, контакты, флаги) — 1:1.
4. **ModelManager:** в оригинале `AntModelManager` разбирает клип `*Model_mc` (дети — `RectShape_com`/`CircleShape_com`/суставы + свойства). В порте источник — `models.json` через `ClipProxy` (класс-обёртка объекта JSON с Flash-подобными полями `x, y, rotation, width, height, scaleX, scaleY` + props; см. `04` §4). `ClipProxy` положи в `src/engine/assets/ClipProxy.ts` — его же будут использовать `Factory`/`Ground`/`LevelCore` (T1.9b).
5. Debug-draw: вместо `AntBox2DDrawer` — функция `collectDebugLines(world) → Float32Array` (фигуры и суставы). Её использует FrameWriter при `hasDebug`.
6. Тесты:
   - хэш `box2d.js`;
   - ящик 1×1 м падает с высоты 100 px на статическую землю и засыпает (sleep) за разумное число шагов; позиция после 35 шагов фиксируется эталоном;
   - `AntModelManager` строит `Shuttle01Model_mc`: число тел, фигур и суставов совпадает с `models.json`, `bodyAliasA/B` резолвятся;
   - контакт-листенер получает `BeginContact` при столкновении двух тел с правильными флагами фильтра.

## Критерии приёмки
- [ ] `box2d.js` из пакета не изменён (тест хэша), импорт работает в renderer, в воркере (build и dev) и в Vitest.
- [ ] Все классы плагина портированы с шапками `// Port of …`.
- [ ] Тесты зелёные; `npm run check` зелёный. Коммит `T1.4: physics`.

## Подводные камни
- `box2d.js` — CommonJS. Если сборщик воркера не делает interop автоматически, добавь `box2dweb` в `optimizeDeps.include` / `worker.rollupOptions`. Не копируй файл в `src/`.
- Единицы: `scale = 30` px/м. Конверсия px ↔ м только через менеджер, как в оригинале.
- Box2DFlash в SWF — «2.1alpha», box2dweb — «2.1a.3». Если найдёшь расхождение API (метод есть в одном, но нет в другом), опиши в отчёте. Не «чини» box2dweb.
