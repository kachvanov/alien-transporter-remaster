# T1.4 — Physics: box2dweb + port of Box2D-for-Anthill + ModelManager

**Milestone:** M1 · **Depends on:** T1.2, T0.7 · **In parallel with:** T1.5, T1.6 · **Size:** L

## Goal
Box2D 2.1a (box2dweb) is plugged in as an immutable vendored module with types. The Anthill Box2D plugin is ported 1:1: manager, bodies, shapes, joints, contacts, flags, models. Body models are built from `assets/data/models.json`.

## Read before starting
- `docs/00-overview.md` (physics parameters), `docs/04-porting-guide.md` §7
- `reference/as3/ru/antkarlov/anthill/plugins/box2d/**` (3528 lines): `AntBox2DManager`, `AntBox2DBody` (extends AntActor!), `AntBox2DContact`, `AntBox2DContactFilter`, `AntBox2DContactListener`, `AntBox2DFlag`, `AntBox2DFlagManager`, `shapes/*`, `joints/*`, `models/AntModelData`, `models/AntModelManager`. `AntBox2DDrawer` → replaced by debug lines in `Frame`
- `reference/as3/Shuttle01Model_mc.as` (shape and joint parameters of the model)

## Steps
1. **Integration:** dependency `box2dweb` at version **exactly `2.1.0-b`**. The file `node_modules/box2dweb/box2d.js` is 10,856 lines, CommonJS, ending with `module.exports = Box2D`, SHA-256 `b44dc71a5958089bcc1c53eb867754bdf73b97c093361e48cf72622e630addb8`. `src/physics/box2dweb/index.ts`: `import Box2D from 'box2dweb'` (CJS interop in Vite/esbuild and Vitest) and a flat re-export of classes (`export const b2World = Box2D.Dynamics.b2World` …). A test checks the SHA-256 of the file in `node_modules` (protection against substitution or patches). `patch-package` and edits are forbidden.
2. `box2d.d.ts`: types only for the API that is actually used. Collect the list with grep over `b2[A-Z]\w*` and method calls in `reference/as3/ru/**` and `plugins/box2d/**`.
3. Port `plugins/box2d/**` into `src/physics/anthill/` 1:1:
   - `AntBox2DManager`: `step = 1/40`, `velocityIterations = 6`, `positionIterations = 15`, `scale = 30`, gravity `(0, 9.81)`, `create()` → `start()` → `AntG.plugins.add(this)`. In `update()`: `Step` + `ClearForces` unless `pause`;
   - `AntBox2DBody` extends `AntActor` (from T1.2) and synchronizes the entity's position and angle with the body, as in the original;
   - the rest (shapes, joints, contacts, flags) — 1:1.
4. **ModelManager:** in the original, `AntModelManager` parses a `*Model_mc` clip (children — `RectShape_com`/`CircleShape_com`/joints + properties). In the port the source is `models.json` via `ClipProxy` (a wrapper class around a JSON object with Flash-like fields `x, y, rotation, width, height, scaleX, scaleY` + props; see `04` §4). Put `ClipProxy` in `src/engine/assets/ClipProxy.ts` — `Factory`/`Ground`/`LevelCore` (T1.9b) will use it too.
5. Debug draw: instead of `AntBox2DDrawer` — a function `collectDebugLines(world) → Float32Array` (shapes and joints). FrameWriter uses it when `hasDebug`.
6. Tests:
   - hash of `box2d.js`;
   - a 1×1 m box falls from a height of 100 px onto static ground and goes to sleep within a reasonable number of steps; the position after 35 steps is pinned to a reference;
   - `AntModelManager` builds `Shuttle01Model_mc`: the number of bodies, shapes and joints matches `models.json`, `bodyAliasA/B` resolve;
   - the contact listener receives `BeginContact` when two bodies with the right filter flags collide.

## Outputs
`src/physics/box2dweb/{index.ts,box2d.d.ts}`, `src/physics/anthill/**`, `src/engine/assets/ClipProxy.ts`, tests.

## Pitfalls
- `box2d.js` is CommonJS. If the worker bundler does not do interop automatically, add `box2dweb` to `optimizeDeps.include` / `worker.rollupOptions`. Do not copy the file into `src/`.
- Units: `scale = 30` px/m. Convert px ↔ m only through the manager, as in the original.
- Box2DFlash in the SWF is "2.1alpha", box2dweb is "2.1a.3". If you find an API discrepancy (a method exists in one but not the other), describe it in the report. Do not "fix" box2dweb.
