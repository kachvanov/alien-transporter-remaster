# T0.3 — `SymbolInfo.java` in the pipeline

**Milestone:** M0 · **Depends on:** T0.2 · **In parallel with:** T0.6 · **Size:** S

## Goal
The `symbols` step: compiles and runs the ready-made utility `tools/extract/java/SymbolInfo.java` → `build/extract/symbols.json` and `build/extract/placements.json`. Plus TS types and zod schemas for reading these files.

## Read before starting
- `docs/02-extraction-pipeline.md` (step 3)
- `tools/extract/java/SymbolInfo.java` — **already written and verified** on this SWF. Do not rewrite it, only integrate it. Edits are allowed only with an explanation in the report.

## Steps
1. `tools/extract/symbols.ts`:
   ```bash
   javac -cp "vendor/jpexs/lib/*" -d build/extract/java tools/extract/java/SymbolInfo.java
   java -Djava.awt.headless=true -cp "vendor/jpexs/lib/*:build/extract/java" SymbolInfo vendor/original/AlienTransporter.swf build/extract
   ```
   Account for the classpath separator: `:` on macOS, `;` on Windows (`path.delimiter`).
2. `tools/extract/types.ts`: zod schemas `SymbolInfo`, `Placement`, `Placements` + loader functions.
3. Test `tools/extract/symbols.test.ts`:
   - 676 symbols with a class in total, of which 590 are `sprite` and 55 are `sound`;
   - `Coin_mc` rect = (−11.9, −11.95) … (12.5, 11.7), frames = 30;
   - `GroundBox_com` rect = (−16, −16, 16, 16);
   - `placements.json` contains 53 clips, `Level01Physic_mc` has 189 placements, of which `GroundBox_com` is 16 and `GroundCircle_com` is 18;
   - all sounds have `sound.format = 2` (MP3).

## Outputs
`tools/extract/{symbols.ts,types.ts,symbols.test.ts}`, `build/extract/{symbols,placements}.json`.

## Acceptance criteria
- [ ] The tests from step 3 are green.
- [ ] `npm run check` is green. Commit `T0.3: symbol info step`.

## Pitfalls
- The JSON is written by hand in Java. If `JSON.parse` fails on some name (special characters), fix the escaping in `q()` and describe it in the report.
