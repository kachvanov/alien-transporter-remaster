# T0.3 — `SymbolInfo.java` в пайплайне

**Милстоун:** M0 · **Зависит от:** T0.2 · **Параллельно с:** T0.6 · **Размер:** S

## Цель
Шаг `symbols`: компилирует и запускает готовую утилиту `tools/extract/java/SymbolInfo.java` → `build/extract/symbols.json` и `build/extract/placements.json`. Плюс TS-типы и zod-схемы для чтения этих файлов.

## Прочитать перед началом
- `docs/02-extraction-pipeline.md` (шаг 3)
- `tools/extract/java/SymbolInfo.java` — **уже написан и проверен** на этом SWF. Не переписывать, только интегрировать. Правки допустимы только с объяснением в отчёте.

## Шаги
1. `tools/extract/symbols.ts`:
   ```bash
   javac -cp "vendor/jpexs/lib/*" -d build/extract/java tools/extract/java/SymbolInfo.java
   java -Djava.awt.headless=true -cp "vendor/jpexs/lib/*:build/extract/java" SymbolInfo vendor/original/AlienTransporter.swf build/extract
   ```
   Учесть разделитель classpath: `:` на macOS, `;` на Windows (`path.delimiter`).
2. `tools/extract/types.ts`: zod-схемы `SymbolInfo`, `Placement`, `Placements` + функции загрузки.
3. Тест `tools/extract/symbols.test.ts`:
   - всего 676 символов с классом, из них 590 `sprite` и 55 `sound`;
   - `Coin_mc` rect = (−11.9, −11.95) … (12.5, 11.7), frames = 30;
   - `GroundBox_com` rect = (−16, −16, 16, 16);
   - `placements.json` содержит 53 клипа, в `Level01Physic_mc` 189 размещений, из них `GroundBox_com` 16 и `GroundCircle_com` 18;
   - у всех звуков `sound.format = 2` (MP3).

## Выходы
`tools/extract/{symbols.ts,types.ts,symbols.test.ts}`, `build/extract/{symbols,placements}.json`.

## Критерии приёмки
- [ ] Тесты из шага 3 зелёные.
