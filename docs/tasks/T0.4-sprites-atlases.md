# T0.4 — Sprite rasterization, atlases, `manifest.json`, alpha masks

**Milestone:** M0 · **Depends on:** T0.3 · **In parallel with:** T0.5, T0.6 · **Size:** L

## Goal
The `sprites` step turns the SWF vector symbols into atlases for the 1x/2x/3x tiers and `assets/manifest.json` with exact registration points. Plus alpha masks for AntLight.

## Read before starting
- `docs/02-extraction-pipeline.md` (step 4 in full, including 4.4.1 and 4.5)
- `reference/as3/ru/alientransporter/Assets.as`, `views/ShuttleView.as`, `reference/data/effects.xml` (CacheList)

## Steps
1. **Export.** For Z ∈ {1, 2, 3}: `-zoom Z -format sprite:png -export sprite build/extract/sprites/${Z}x` (cached by the SWF hash). At 2x this takes ~47 s, longer at 3x — run three Java processes in parallel.
2. **Whitelist/blacklist** strictly per `02` §4.2 → `build/extract/whitelist.json`. Report missing and unaccounted symbols.
3. **Origin.** For each symbol: `origin_Z = (−rectWithFilters.xMin·Z, −rectWithFilters.yMin·Z)`. Check: PNG size = `ceil((xMax−xMin)·Z)` ±1 (otherwise an error naming the symbol). This formula has been verified on all 590 sprites.
4. **Level layers** `LevelNN{Back,BG,FG}_mc`: crop the symbol area `[0,800)×[0,600)` → PNG `800Z×600Z`, origin `(0, 0)`, no trim.
5. **Trim and dedupe** the remaining frames (sharp `trim`/raw buffers). Dedupe by sha1 of RGBA within a symbol.
6. **Overrides** (`tools/extract/asset-overrides.json`, see `02` §4.3).
7. **Groups** per `tools/extract/groups.json` (regex rules, first match wins) and maxrects **packing** (4096, padding 2, extrude 1). Output `assets/gfx/{tier}/{group}-{n}.png`.
8. **Bitmap-font images** (`reference/data/fonts/*.png`) go into the `ui` group as symbols `Font:<name>` (one frame, origin 0,0); glyphs are later cut according to the font JSON.
9. **manifest.json** per the schema in `02` §4.5 + a zod schema in `src/engine/assets/schemas.ts` (the engine uses the same one). `texId` is stable: symbols sorted by name, frames in order.
10. **Alpha masks** (`02` §4.4.1): 1x, before trim, `alpha > 0`, for the symbols from `views/ShuttleView.as` and its children (collect the list from the code and record it in `tools/extract/alphamask-symbols.json`).
11. **Summary:** number of symbols, frames and unique frames, atlases per tier and group, Mpx per tier, top 20 symbols by area.
12. Tests `tools/extract/sprites.test.ts`:
    - every whitelist symbol has frames in all tiers (taking `maxTier` into account);
    - the blacklist is absent;
    - `Coin_mc` has 30 frames, `origin1x ≈ (11.9, 11.95)`;
    - `MainMenuBG_mc#0` — size1x (800, 600), origin (0, 0);
    - `Level01BG_mc#0` at 2x has a 1600×1200 rectangle;
    - atlases at 2x for groups other than `level-*` ≤ 4 (otherwise the test prints the top symbols and fails).

## Outputs
`tools/extract/{sprites.ts,groups.json,asset-overrides.json,alphamask-symbols.json,sprites.test.ts}`, `assets/gfx/**`, `assets/manifest.json`, `assets/data/alphamasks.bin`, `src/engine/assets/schemas.ts` (manifest).

## Acceptance criteria
- [ ] The tests from step 12 are green.
- [ ] The report includes the summary from step 11.
- [ ] The contact sheet `build/extract/debug/contact-2x.png` (the first frame of each symbol, with labels) is attached to the report as a path; visually there are no empty or cropped frames.
- [ ] `npm run check` is green. Commit `T0.4: sprites and atlases`.

## Pitfalls
- `AGIntro_mc` is 218 full-screen frames (435 Mpx at 2x). It is in the blacklist: do not spend export time on it if JPEXS lets you select symbols (otherwise just skip it in post-processing).
- JPEXS exports **all** sprites, including unnamed nested clips. Take only the folders whose id is in the whitelist.
- Do not use premultiplied alpha in PNGs. Pixi handles it itself; we need a "straight" alpha channel, as in the export.
- At 3x the atlases may not fit into 4096 — that is fine, there will be more of them. Check that no frame exceeds 4096 (otherwise lower its tier via an override).
