# T4.6 — Сборка Windows 10 x64 (NSIS + portable)

**Милстоун:** M4 · **Зависит от:** T2.8, T3.6 · **Параллельно с:** T4.5 · **Размер:** S

## Цель
Установщик `Alien Transporter Remaster Setup <ver>.exe` и portable `Alien Transporter Remaster <ver>.exe`, которые работают на ноутбуке с Windows 10 x64 и 8 ГБ ОЗУ.

## Шаги
1. `electron-builder.yml`, win:
   - `target: [nsis, portable]`, `arch: x64`, иконка `resources/icon.ico`;
   - `nsis.oneClick: false`, `allowToChangeInstallationDirectory: true`, `createDesktopShortcut: true`;
   - `extraResources` — только тиры 1x/2x (T4.4).
2. **Путь А (предпочтительно): кросс-сборка на Маке.** `npm run build:win`. Если electron-builder требует Wine (для rcedit, иконки, версии exe) — `brew install --cask --no-quarantine wine-stable` (на Apple Silicon нужен Rosetta 2: `softwareupdate --install-rosetta`). Результат проверить на Windows.
3. **Путь Б (запасной): GitHub Actions.** `.github/workflows/build-win.yml` на `windows-latest`: checkout → `setup-node` → `setup-java@v4 (17)` → установка ffmpeg (`choco install ffmpeg`) → нужен SWF, а он **не должен попадать в репозиторий**. Вариант — репозиторий приватный и SWF кладётся в зашифрованный секрет или артефакт; вариант проще — собрать `assets/` на Маке и загрузить их как артефакт или release-asset в приватный репозиторий. Выбрать с пользователем (вопрос в отчёте), ничего публично не выкладывать.
4. Запуск на Windows 10: SmartScreen («Подробнее → Выполнить в любом случае»), Defender Firewall при хостинге («Частные сети»).
5. Проверка по `05` §10 (Windows) и бюджеты `05` §9.

## Критерии приёмки
- [ ] Оба exe работают на Windows 10 x64, прогресс в `%APPDATA%/<productName>/`.
- [ ] LAN Mac ↔ Windows между собранными версиями работает в обе стороны.
- [ ] Коммит `T4.6: windows build`.
