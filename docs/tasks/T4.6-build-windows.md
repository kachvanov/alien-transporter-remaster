# T4.6 — Windows 10 x64 build (NSIS + portable)

**Milestone:** M4 · **Depends on:** T2.8, T3.6 · **In parallel with:** T4.5 · **Size:** S

## Goal
The installer `Alien Transporter Remaster Setup <ver>.exe` and the portable `Alien Transporter Remaster <ver>.exe`, which work on a Windows 10 x64 laptop with 8 GB of RAM.

## Steps
1. `electron-builder.yml`, win:
   - `target: [nsis, portable]`, `arch: x64`, the icon `resources/icon.ico`;
   - `nsis.oneClick: false`, `allowToChangeInstallationDirectory: true`, `createDesktopShortcut: true`;
   - `extraResources` — only tiers 1x/2x (T4.4).
2. **Path A (preferred): cross-build on the Mac.** `npm run build:win`. If electron-builder requires Wine (for rcedit, the icon, the exe version) — `brew install --cask --no-quarantine wine-stable` (Apple Silicon needs Rosetta 2: `softwareupdate --install-rosetta`). Verify the result on Windows.
3. **Path B (fallback): GitHub Actions.** `.github/workflows/build-win.yml` on `windows-latest`: checkout → `setup-node` → `setup-java@v4 (17)` → install ffmpeg (`choco install ffmpeg`) → the SWF is needed, and it **must not end up in the repository**. One option — the repository is private and the SWF is put into an encrypted secret or an artifact; a simpler option — build `assets/` on the Mac and upload them as an artifact or a release asset in a private repository. Choose with the user (a question in the report); publish nothing publicly.
4. Run on Windows 10: SmartScreen ("More info → Run anyway"), Defender Firewall when hosting ("Private networks").
5. Verification per `05` §10 (Windows) and the `05` §9 budgets.

## Acceptance criteria
- [ ] Both exes work on Windows 10 x64, progress in `%APPDATA%/<productName>/`.
- [ ] LAN Mac ↔ Windows between the built versions works in both directions.
- [ ] Commit `T4.6: windows build`.
