# T4.7 — README для пользователя (на русском)

**Милстоун:** M4 (финальная) · **Зависит от:** T4.5, T4.6, T3.7 · **Размер:** S

## Цель
Понятная инструкция для владельца и его девушки: как установить, как играть одному, вдвоём и по сети, что делать, если сеть не видит друг друга.

## Шаги
Создать `README.md` в корне (для людей, не для агентов; агенты читают `CLAUDE.md`):
1. Что это (одна фраза), для личного использования, права на оригинал у автора.
2. **Установка на Mac:** открыть dmg → перетащить в Applications → первый запуск (если «повреждено» — команда `xattr -cr` / `codesign` из T4.5).
3. **Установка на Windows 10:** установщик или portable. SmartScreen: «Подробнее → Выполнить в любом случае».
4. **Управление:** P1 — стрелки, P2 — W/A/D, пауза — P/Esc, F11 — полный экран, F2 — настройки ремастера, F3 — счётчик производительности. Клавиши меняются в Garage.
5. **Вдвоём на одном компьютере:** во время уровня второй игрок жмёт W.
6. **По сети (как в Minecraft):**
   - оба в одной Wi-Fi;
   - один: Online → Host Game (видит свой IP);
   - второй: Online → Join Game → выбрать игру в списке или ввести IP → Connect;
   - хост выбирает уровень, клиент входит газом.
7. **Если не подключается:**
   - Windows: разрешить в брандмауэре «Частные сети»; сеть должна быть «Частная» (Параметры → Сеть → Wi-Fi → Свойства); проверка `Test-NetConnection <ip> -Port 47020`;
   - Mac: Системные настройки → Конфиденциальность → Локальная сеть → включить для игры; фаервол macOS — разрешить входящие;
   - гостевые Wi-Fi сети часто блокируют соединения между устройствами;
   - версии игры у обоих должны совпадать.
8. **Где лежат сохранения** на обеих ОС. Как сбросить прогресс.
9. **Для разработчика:** ссылка на `CLAUDE.md` и `docs/`; как пересобрать (`npm ci`, `.env`, `npm run extract`, `npm run build:mac|win`).
