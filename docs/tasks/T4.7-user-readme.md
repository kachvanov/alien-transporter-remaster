# T4.7 — User README (in English)

**Milestone:** M4 (final) · **Depends on:** T4.5, T4.6, T3.7 · **Size:** S

## Goal
Clear instructions for the owner and the second player: how to install, how to play solo, two-player and over the network, and what to do if the machines do not see each other on the network.

## Steps
Create `README.md` in the root (for humans, not for agents; agents read `CLAUDE.md`):
1. What this is (one sentence), for personal use, the rights to the original belong to the author.
2. **Installation on Mac:** open the dmg → drag to Applications → first launch (if "damaged" — the `xattr -cr` / `codesign` command from T4.5).
3. **Installation on Windows 10:** installer or portable. SmartScreen: "More info → Run anyway".
4. **Controls:** P1 — arrows, P2 — W/A/D, pause — P/Esc, F11 — fullscreen, F2 — remaster settings, F3 — performance counter. The keys can be changed in the Garage.
5. **Two players on one computer:** during a level the second player presses W.
6. **Over the network (like Minecraft):**
   - both on the same Wi-Fi;
   - one: Online → Host Game (sees their own IP);
   - the other: Online → Join Game → pick a game from the list or enter the IP → Connect;
   - the host picks a level, the client joins with throttle.
7. **If it does not connect:**
   - Windows: allow it in the firewall for "Private networks"; the network must be "Private" (Settings → Network → Wi-Fi → Properties); check with `Test-NetConnection <ip> -Port 47020`;
   - Mac: System Settings → Privacy → Local Network → enable for the game; macOS firewall — allow incoming connections;
   - guest Wi-Fi networks often block connections between devices;
   - the game versions on both machines must match.
8. **Where the saves are** on both OSes. How to reset progress.
9. **For the developer:** a link to `CLAUDE.md` and `docs/`; how to rebuild (`npm ci`, `.env`, `npm run extract`, `npm run build:mac|win`).
