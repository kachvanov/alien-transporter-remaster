# T1.8 — Sound: port of AntSound/AntSoundManager + AudioEngine

**Milestone:** M1 · **Depends on:** T1.2, T0.5, T1.7 · **In parallel with:** T1.9a–d · **Size:** M

## Goal
The original's sound logic (volume, pan by source position, averaging, fade, mute) works in the simulation and emits the channel state into the `Frame`. The renderer plays it through Web Audio accurately and without clicks.

## Read before starting
- `reference/as3/ru/antkarlov/anthill/{AntSound,AntSoundManager}.as`, `reference/as3/ru/alientransporter/{Sounds,Music,MusicManager}.as`
- `docs/01-architecture.md` §6, `docs/03-frame-and-network-protocol.md` §1 (OneShot/Loop)

## Steps
1. `src/engine/sound/AntSoundManager.ts`, `AntSound.ts` — 1:1, without `flash.media`. Instead of `Sound.play()`, a registry of active channels `{channelId, soundId, loop, volume, pan}` is kept. One-shot sounds go into the current tick's oneShots list. The final volume/pan come from `_volumeAdjust`, `_panAdjust`, `parent.volume`, `mute` — like `soundTransform` in the original.
2. Names → soundId: from `AssetRegistry.getSounds()` (`sounds.json`). `ru/alientransporter/Sounds.as` and `Music.as` in the original register sounds by class (`Sounds_SndHitBox01`) — in the port, by name (`SndHitBox01`).
3. FrameWriter (T1.5) takes `oneShots` and `loops` from `AntG.sounds`. Music (`MusicManager` — T2.7, `STUB(T2.7)` for now) is written into `musicTrack`/`musicVol`.
4. `src/audio/AudioEngine.ts` (renderer):
   - `init(sounds.json)` → `decodeAudioData` of all OGGs (in parallel), taking `trimStartSamples` into account (`loopStart`/`offset`);
   - `apply(frame)` → oneShots (`BufferSource → StereoPanner → Gain → master`), reconcile loops by `channelId` (start / stop with a 20 ms fade / smooth gain and pan changes via `setTargetAtTime(…, 0.03)`), music (`musicTrack` changed → 200 ms crossfade or as in the original MusicManager), mute flags;
   - create or resume the `AudioContext` on the first user input (autoplay policy). In Electron you can use `app.commandLine.appendSwitch('autoplay-policy', 'no-user-gesture-required')` — do it in main.
5. Tests:
   - sim side: a sound whose source is to the right of center gives pan > 0; mute zeroes the volume; a loop stays in `loops` until stopped;
   - AudioEngine: the pure loop-reconciliation function (diff: start/stop/update) is tested without Web Audio.

## Outputs
`src/engine/sound/**`, `src/audio/**`, FrameWriter changes, tests.

## Acceptance criteria
- [ ] In the test scene the engine loop (`SndEngineGas`) is audible, its pan follows the object, the seam has no clicks.
- [ ] `npm run check` is green. Commit `T1.8: audio`.

## Pitfalls
- Do not create a new `GainNode` or `StereoPannerNode` per frame for loops: keep the graph per channel.
- There may be several identical oneShots per tick (coins). Play them that way if the original does (no dedup).
