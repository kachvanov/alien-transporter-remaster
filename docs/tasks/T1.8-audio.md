# T1.8 — Звук: порт AntSound/AntSoundManager + AudioEngine

**Милстоун:** M1 · **Зависит от:** T1.2, T0.5, T1.7 · **Параллельно с:** T1.9a–d · **Размер:** M

## Цель
Логика звука оригинала (громкость, панорама по позиции источника, усреднение, fade, mute) работает в симуляции и выдаёт состояние каналов в `Frame`. Рендерер через Web Audio проигрывает его точно и без щелчков.

## Прочитать перед началом
- `reference/as3/ru/antkarlov/anthill/{AntSound,AntSoundManager}.as`, `reference/as3/ru/alientransporter/{Sounds,Music,MusicManager}.as`
- `docs/01-architecture.md` §6, `docs/03-frame-and-network-protocol.md` §1 (OneShot/Loop)

## Шаги
1. `src/engine/sound/AntSoundManager.ts`, `AntSound.ts` — 1:1, без `flash.media`. Вместо `Sound.play()` ведётся реестр активных каналов `{channelId, soundId, loop, volume, pan}`. Однократные звуки попадают в список oneShots текущего тика. Итоговые volume/pan — из `_volumeAdjust`, `_panAdjust`, `parent.volume`, `mute` — как `soundTransform` в оригинале.
2. Имена → soundId: из `AssetRegistry.getSounds()` (`sounds.json`). `ru/alientransporter/Sounds.as` и `Music.as` в оригинале регистрируют звуки по классам (`Sounds_SndHitBox01`) — в порте по имени (`SndHitBox01`).
3. FrameWriter (T1.5) берёт `oneShots` и `loops` из `AntG.sounds`. Музыку (`MusicManager` — T2.7, пока `STUB(T2.7)`) пишет в `musicTrack`/`musicVol`.
4. `src/audio/AudioEngine.ts` (renderer):
   - `init(sounds.json)` → `decodeAudioData` всех OGG (параллельно), с учётом `trimStartSamples` (`loopStart`/`offset`);
   - `apply(frame)` → oneShots (`BufferSource → StereoPanner → Gain → master`), сверка loops по `channelId` (start / stop с fade 20 мс / плавное изменение gain и pan через `setTargetAtTime(…, 0.03)`), музыка (`musicTrack` сменился → кроссфейд 200 мс или как в оригинальном MusicManager), mute-флаги;
   - `AudioContext` создавать или возобновлять по первому пользовательскому вводу (autoplay policy). В Electron можно `app.commandLine.appendSwitch('autoplay-policy', 'no-user-gesture-required')` — сделай это в main.
5. Тесты:
   - сим-сторона: звук с источником справа от центра даёт pan > 0; mute обнуляет громкость; луп живёт в `loops`, пока не остановлен;
   - AudioEngine: чистая функция сверки loops (дифф: старт/стоп/апдейт) тестируется без Web Audio.

## Выходы
`src/engine/sound/**`, `src/audio/**`, правки FrameWriter, тесты.

## Критерии приёмки
- [ ] В тестовой сцене слышен луп двигателя (`SndEngineGas`), его панорама следует за объектом, стык без щелчков.
- [ ] `npm run check` зелёный. Коммит `T1.8: audio`.

## Подводные камни
- Не создавай новый `GainNode` или `StereoPannerNode` на каждый кадр для лупов: держи граф на канал.
- oneShot'ов за тик может быть несколько одинаковых (монеты). Так и проигрывай, если так делает оригинал (без дедупа).
