# T2.2 — elements/: PhysicalMap + ElementSimulation (smoke, fire, oil)

**Milestone:** M2 · **Depends on:** M1 · **In parallel with:** T2.1, T2.3–T2.5 · **Size:** M (~1.1K lines of AS3)

## Goal
Smoke, engine-fire and oil particles behave as in the original: an SPH-like simulation (density, pressure, neighbors) with collisions against the physics world, and it looks the same.

## Read before starting
- `reference/as3/ru/alientransporter/elements/*`: `PhysicalMap` (242), `PhysicalCell` (37), `ElementSimulation` (335), `Particle` (457), `ParticleCell` (45)
- `views/{BasicParticleView,FireParticleView,SmokeParticleView,OilParticleView}.as`
- `states/GameState.as` (creation of `physicalMap`, `oilSimulation`, `smokeSimulation`, `fireSimulation`), `systems/ShuttleSystem.as:181` (`fireSimulation.pour`)

## Steps
1. Port 1:1. `PhysicalMap` uses `AntBox2DManager` (AABB queries against fixtures) — via the box2dweb API.
2. `ElementSimulation.draw` in the original **draws** the particles. In the port, the logic of `draw` (if it has any besides drawing) moves to the render point, and the particles are AntActor views (`FireParticleView`, etc.) that go into the `Frame` as ordinary nodes.
3. `FireParticleView`: `blend = fancyEffects ? "add" : null` — this comes from the settings.
4. Remove `STUB(T2.2)` from ShuttleSystem/GameState/LevelCore.
5. Tests: `pour` creates N particles; particles do not pass through static ground (100 ticks — no particle ends up inside the ground fixtures); `clear()` removes everything.

## Outputs
`src/game/elements/**`, `src/game/views/*ParticleView.ts`, tests.

## Acceptance criteria
- [ ] The engine fire under throttle looks like the original (compare with Ruffle on Level01; the report has a description and screenshots of both).
- [ ] A simulation tick with two shuttles' fire active on an M5 takes < 1 ms (measurement in the report).
- [ ] `npm run check` is green. Commit `T2.2: element simulation`.

## Pitfalls
- This is a probable hot path. Do not optimize anything here: an exact port first, optimization in T4.3 under golden tests.
