# T3.4 — Экраны Online (Host/Join, ввод IP, найденные игры)

**Милстоун:** M3 · **Зависит от:** T2.6, T3.5 · **Размер:** M

## Цель
В главном меню появилась кнопка «Online». Через неё можно захостить игру или подключиться — по IP или из списка найденных в LAN. Выглядит как родная часть оригинала: те же фоны, кнопки, растровые шрифты и звуки.

## Прочитать перед началом
- `reference/as3/ru/alientransporter/screens/{BasicScreen,MainMenuScreen,SelectLevelScreen}.as` (стиль, кнопки, переходы), `ui/{ConfirmPopupView,KeyInputPopupView}.as`
- `docs/03-frame-and-network-protocol.md` §3, §7, §8

## Шаги
1. Экраны — **часть симуляции** (как остальные screens), кнопки из `BtnBasic_mc` / `BtnGreen_mc` и т.п. с подписями Label. Новые экраны, которых нет в оригинале, помечаются `// DEVIATION: online`.
2. **MainMenuScreen:** добавить кнопку «ONLINE» в свободное место колонки кнопок (там, где была удалённая спонсорская). Если места нет — под «PLAY» со сдвигом, согласовать с визуальным балансом (скриншот в отчёте).
3. **OnlineScreen:** «HOST GAME», «JOIN GAME», «BACK».
4. **HostScreen:**
   - IPv4-адреса машины и порт (из main через воркер-сообщение), статус «WAITING FOR PLAYER…», затем «PLAYER 2 CONNECTED: <name>»;
   - кнопки «START» (переход к выбору уровня, дальше игра идёт как обычно) и «STOP»;
   - хост стартует ws-сервер и UDP-beacon при входе на экран и останавливает при «STOP»/«BACK».
5. **JoinScreen:**
   - список найденных игр (до 5 строк: имя хоста, IP, статус, «different version» серым), клик — подключение;
   - поле ввода адреса: собственный текстовый инпут на Label, принимает цифры, точку и двоеточие, Backspace, Enter = Connect. Ввод идёт из воркер-клавиатуры: коды цифр и точки есть в `AntKeyboard`;
   - кнопки «CONNECT», «BACK»; последний адрес подставляется из настроек.
6. Подключение. Т.к. клиент не запускает симуляцию, JoinScreen шлёт команду в renderer: `{t:'joinRequest', host, port}` → `src/app` останавливает воркер и запускает `clientSession` (T3.3). При ошибке или обрыве renderer перезапускает воркер и открывает JoinScreen с сообщением («Connection failed», «Host is full», «Different game version», «Connection lost»).
7. Тексты — английские, в стиле оригинала (капс, растровый шрифт `font04` или какой используют похожие экраны).

## Выходы
`src/game/screens/{OnlineScreen,HostScreen,JoinScreen}.ts`, `src/game/ui/TextInputView.ts`, правки `MainMenuScreen`, `src/app/*`.

## Критерии приёмки
- [ ] Весь поток Host/Join проходит мышью и клавиатурой на двух экземплярах одного Мака.
- [ ] Скриншоты новых экранов рядом с оригинальными экранами (единый стиль) — в отчёте.
- [ ] `npm run check` зелёный. Коммит `T3.4: online screens`.

## Подводные камни
- Не используй HTML-инпуты поверх canvas: вид должен быть родным. Исключение — если bitmap-ввод невозможно сделать доступным; тогда обсуди в отчёте.
