# T2.5 — ui/: all interface views + full Label

**Milestone:** M2 · **Depends on:** M1 · **In parallel with:** T2.1–T2.4 · **Size:** L (~2.9K lines of AS3)

## Goal
All of the original's interface elements: pause, game-over, confirmation, key-input and mission popups; level-statistics screens and stars; notifications; ship previews; button bars; transitions.

## Read before starting
- `reference/as3/ru/alientransporter/ui/*` (28 files): `ButtonBarView`, `ConfirmPopupView`, `FadeEffectView`, `GameOverPopupView`, `KeyInputPopupView`, `LevelStarView`, `LevelStatsColumn`, `LevelStatsGoalView`, `LevelStatsStarsView`, `LevelStatsView`, `MissionBarUIView`, `MissionPopupView`, `NotifyView`, `PausePopupView`, `PopupFadeView`, `ScreenFadeView`, `ShipSelectorView`, `ShipSelectorWaveView`, `ShuttlePreviewView` and the HUD views not done in T1.9e
- `screens/{Button,ButtonController,ButtonSwitch}.as` — needed by the popups (mouse buttons)
- `reference/as3/ru/alientransporter/texts/Text.as` + `assets/data/texts.json`

## Steps
1. `screens/Button`, `ButtonController`, `ButtonSwitch` — 1:1: mouse hover and click (`AntMouse`), sounds `SndOverButton`/`SndClickButton`, `blend = "add"` on the highlight.
2. All views from the list — 1:1. `MissionBarUIView` uses `blend = "overlay"` — check it in the renderer (advanced blend modes).
3. `Text` — 1:1 on top of `texts.json` (`*_visual` → a text image symbol).
4. Label — finish everything that was not needed in T1.9e: multi-line, alignment, `charInterval`, color, blend, digit animations (if any).
5. Remove `STUB(T2.5)`.
6. Tests: `PausePopupView` shows 3 toggles with states from `GameData`; `KeyInputPopupView` accepts a key and returns a name from `AvailKeys`; Label: the string width by font metrics = reference.

## Outputs
`src/game/ui/**`, `src/game/screens/{Button,ButtonController,ButtonSwitch}.ts`, `src/game/texts/Text.ts`, tests.
