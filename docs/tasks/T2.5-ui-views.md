# T2.5 — ui/: все view интерфейса + полный Label

**Милстоун:** M2 · **Зависит от:** M1 · **Параллельно с:** T2.1–T2.4 · **Размер:** L (~2.9K строк AS3)

## Цель
Все элементы интерфейса оригинала: попапы паузы, game over, подтверждения, ввода клавиши, миссий; экраны статистики уровня и звёзды; уведомления; превью кораблей; кнопки-бары; переходы.

## Прочитать перед началом
- `reference/as3/ru/alientransporter/ui/*` (28 файлов): `ButtonBarView`, `ConfirmPopupView`, `FadeEffectView`, `GameOverPopupView`, `KeyInputPopupView`, `LevelStarView`, `LevelStatsColumn`, `LevelStatsGoalView`, `LevelStatsStarsView`, `LevelStatsView`, `MissionBarUIView`, `MissionPopupView`, `NotifyView`, `PausePopupView`, `PopupFadeView`, `ScreenFadeView`, `ShipSelectorView`, `ShipSelectorWaveView`, `ShuttlePreviewView` и HUD-view, не сделанные в T1.9e
- `screens/{Button,ButtonController,ButtonSwitch}.as` — нужны попапам (кнопки мышью)
- `reference/as3/ru/alientransporter/texts/Text.as` + `assets/data/texts.json`

## Шаги
1. `screens/Button`, `ButtonController`, `ButtonSwitch` — 1:1: наведение и клик мышью (`AntMouse`), звуки `SndOverButton`/`SndClickButton`, `blend = "add"` у подсветки.
2. Все view из списка — 1:1. `MissionBarUIView` использует `blend = "overlay"` — проверь в рендере (advanced blend modes).
3. `Text` — 1:1 поверх `texts.json` (`*_visual` → символ-картинка текста).
4. Label — доделать всё, что не понадобилось в T1.9e: многострочность, выравнивание, `charInterval`, цвет, blend, анимации цифр (если есть).
5. Убрать `STUB(T2.5)`.
6. Тесты: `PausePopupView` показывает 3 переключателя с состояниями из `GameData`; `KeyInputPopupView` принимает клавишу и возвращает имя из `AvailKeys`; Label: ширина строки по метрикам шрифта = эталон.

## Выходы
`src/game/ui/**`, `src/game/screens/{Button,ButtonController,ButtonSwitch}.ts`, `src/game/texts/Text.ts`, тесты.
