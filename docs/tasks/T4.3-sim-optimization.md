# T4.3 — Simulation optimization without changing behavior

**Milestone:** M4 · **Depends on:** T4.1, T2.8 · **Size:** M

## Goal
Fulfill the user's requirement "optimize the physics, but the physics stays the same". A simulation tick fits the budget on a weak Windows laptop (p95 ≤ 4 ms), while **all golden hashes stay the same, bit for bit**.

## Read before starting
- `docs/05-verification.md` §4, §9; `docs/01-architecture.md` §3

## Steps
1. **Profiling.** `--perf-log=perf.json` (implement it if missing): once per second FPS, p50/p95 of the tick time and, separately, the shares of `plugins.update` (physics + systems), FrameWriter, ElementSimulation, AntLight. Scenarios Level11 and Level13 for two players, 60 s of scripted input. Chrome DevTools Performance for the worker.
2. **Allowed:**
   - remove allocations on hot paths of game code (reusable `b2Vec2`/`AntPoint`; no closures in loops);
   - caching of values that are guaranteed not to change (for example, frame metadata);
   - data structures in `ElementSimulation`/`PhysicalMap` (typed arrays, pools) **with the same order of arithmetic operations** (the order of float additions affects the result!);
   - FrameWriter without allocations.
3. **Forbidden:**
   - changing box2dweb, the `Step` parameters, the system order, the object creation order;
   - changing formulas or their evaluation order;
   - "approximate" optimizations.
4. After each optimization: `vitest run tests/golden` — the hashes did not change. If they changed, revert or redo the optimization. Updating the references is forbidden.
5. Report: a "before/after" table (p50/p95 tick, subsystem shares) on an M5 and on a Windows laptop (if available; otherwise on an M5 with CPU throttling ×4 in DevTools as an approximation).

## Outputs
Optimizations in `src/**`, `--perf-log`, a report with numbers.

## Acceptance criteria
- [ ] All golden replays are green without updating the references.
- [ ] The tick budget from `05` §9 is met (or it is shown that it was already met, and what exactly was improved).
- [ ] `npm run check` is green. Commit `T4.3: sim optimization`.
