# T1.5 — Формат `Frame`: writer, reader, uid, teleport

**Милстоун:** M1 · **Зависит от:** T1.2 · **Параллельно с:** T1.4 · **Размер:** M

## Цель
`src/frame`: сериализация сцены (дерево AntEntity + звук + свет) в бинарный `Frame` строго по `docs/03-frame-and-network-protocol.md` §1 и обратное чтение. Это единственный контракт между симуляцией, рендером и сетью.

## Прочитать перед началом
- `docs/03-frame-and-network-protocol.md` §1 целиком, `docs/01-architecture.md` §3–§5
- `reference/as3/ru/antkarlov/anthill/{AntEntity,AntActor,AntCamera}.as` — как оригинал рисует: порядок обхода детей, `visible/exists/onScreen`, применение `scrollFactor`, `origin`, `angle`, `scale`, `alpha`, `color`, `blend`

## Шаги
1. `src/frame/constants.ts`: типы сообщений, биты флагов, ext-типы, `MAX_NODES = 65535`.
2. `src/frame/types.ts`: `FrameData { tick, flags, musicTrack, musicVol, muteFlags, levelGroup, tickCost, nodes: NodeData[], oneShots, loops }`, `NodeData { uid, texId, flags, x, y, rotation, scaleX, scaleY, alpha, tint, ext? }`, `LightExt`, `DebugLinesExt`.
3. `src/frame/FrameReader.ts` — `readFrame(buf: ArrayBuffer): FrameData` с проверкой границ и понятной ошибкой `FrameDecodeError`.
4. `src/frame/FrameWriter.ts`:
   - Растущий `ArrayBuffer` (переиспользуется между тиками, отдаётся `slice()`-копией).
   - `write(scene: { root: AntEntity, camera: AntCamera, audio, lights, level, ... }) → ArrayBuffer`.
   - Обход дерева **в порядке оригинальной отрисовки** (как `AntEntity.draw` → `drawChildren`). Узел пишется, если `exists && visible` у него и у предков и у `AntActor` есть кадр.
   - Экранные координаты: `global − camera.scroll × scrollFactor + shakeOffset`. Угол в радианах. Итоговый масштаб, alpha и цвет — как в `AntActor.drawActor`.
   - Позиция спрайта = точка регистрации (origin) кадра. Рендерер ставит anchor по `origin1x`.
   - uid = `(entity.entityId << 8) | subIndex`. `entityId` выдаётся в конструкторе AntBasic (монотонный u24).
   - teleport — по правилам `03` §1.
5. Хук «точки рендера» в `Anthill.tick` (T1.2): FrameWriter вызывается между `state.postUpdate()` и `plugins.update()`.
6. Тесты: round-trip (пустой кадр, 1000 узлов со всеми флагами, свет со 100 точками, debug-линии); ошибка на обрезанном буфере; порядок узлов = порядок обхода дерева (тестовое дерево из 3 уровней); `exists=false` у родителя скрывает детей; teleport при `reset()`.

## Выходы
`src/frame/**`, тесты.

## Критерии приёмки
- [ ] Формат байт в байт соответствует `03` §1 (тест с «золотым» буфером на маленьком кадре — массив байт в тесте).
- [ ] Запись 600 узлов — < 0.3 мс на M5 (микробенчмарк в тесте, мягкий порог, только лог).
- [ ] `npm run check` зелёный. Коммит `T1.5: frame format`.

## Подводные камни
- `DataView` всегда с `littleEndian = true`.
- Не создавай объекты на каждый узел при записи (без аллокаций в горячем пути).
