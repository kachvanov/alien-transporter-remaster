# T1.9e — GameState (layers), Label/fonts, HUD → Level01 playable

**Milestone:** M1 (closing task) · **Depends on:** T1.9c, T1.9d, T1.6, T1.7, T1.8, T0.6 · **Size:** L

## Goal
Assemble the vertical slice. `npm run dev -- --start-level=Level01` launches the first level in a window with a HUD and sound. It can be played solo; P2 joins with the W key — as in the original.

## Read before starting
- `reference/as3/ru/alientransporter/states/GameState.as` (248), `fonts/{Font(195),Label(431)}.as`, `systems/UISystem.as` (354), `ui/{ShuttleUIView,FuelBarUIView,HullBarUIView,PassengerBarUIView,ShuttleLabelUIView,PlayerJoinUIView,LevelTitleUIView,TextUIView,FuelIndicatorView}.as`, `screens/GameScreen.as` (310 — the relevant part)
- `docs/01-architecture.md` §3–§5

## Steps
1. `GameState` 1:1: 22 layers in the exact order (`layerBack`, `layerBackEffects`, `layerBG`, `layerBGPassengers`, `layerHouses`, `layerIndicators`, `layerMain`, `layerPhysic`, `layerFGPassengers`, `layerFragments`, `layerEngineEffects`, `layerShuttles`, `layerBonuses`, `lightEnvironment`, `layerMainEffects`, `layerFG`, `layerRocks`, `layerFrontEffects`, `layerInterface`, `layerMenuBG`, `layerMenu`, `layerMenuFG`, `layerPopups` — verify against the code), `PhysicalMap` and the simulations (`STUB(T2.2)`), `lightEnvironment` (`STUB(T2.4)`), the camera `AntCamera(0,0,800,600)` with `follow(cameraAnchor)`, system registration as in the original.
2. Dev entry `GameState.debugStartLevel(name)`: bypassing the menu, `G.gameData` for Solo, `LevelManager.loadLevel(name)`. The `--start-level` flag → a command to the worker (T1.6).
3. `Font` and `Label` 1:1, without BitmapData: Label holds the string, font, alignment, color, blend. `FrameWriter` (T1.5) emits glyphs as nodes with `subIndex` (a glyph's texId is a `Font:<name>` frame with a sub-rectangle; extend the T0.4 manifest generator or add runtime sub-textures: preferably in the manifest under the key `Font:<name>#<charCode>`). The side logic of `Label.draw` (rebuilding the buffer when the text changes) → moves to the render point.
4. `UISystem` and the HUD views from the list above — 1:1 (without the pause and game-over popups: they are in T2.5, `STUB(T2.5)`).
5. A manual end-to-end check: flight, landing, refueling, passengers, portal, end of level (the completion screen may be `STUB(T2.6)` — log "level complete"), P2 joining via W, sound.
6. e2e (`tests/e2e/level01.spec.ts`): launch with `--start-level=Level01`, 10 s of scripted input (throttle/left/right), no errors in the console, `Frame`s arrive at 35/s.

## Outputs
`src/game/states/GameState.ts`, `src/game/fonts/**`, `src/game/systems/UISystem.ts`, `src/game/ui/*` (HUD), FrameWriter/manifest changes for glyphs, e2e.

- If something looks "not like I remember it", compare with Ruffle (`/Applications/Ruffle.app`), not with memory.
