## Шаги
1. `GameState` 1:1: 22 слоя в точном порядке (`layerBack`, `layerBackEffects`, `layerBG`, `layerBGPassengers`, `layerHouses`, `layerIndicators`, `layerMain`, `layerPhysic`, `layerFGPassengers`, `layerFragments`, `layerEngineEffects`, `layerShuttles`, `layerBonuses`, `lightEnvironment`, `layerMainEffects`, `layerFG`, `layerRocks`, `layerFrontEffects`, `layerInterface`, `layerMenuBG`, `layerMenu`, `layerMenuFG`, `layerPopups` — сверить с кодом), `PhysicalMap` и симуляции (`STUB(T2.2)`), `lightEnvironment` (`STUB(T2.4)`), камера `AntCamera(0,0,800,600)` с `follow(cameraAnchor)`, регистрация систем как в оригинале.
2. Dev-вход `GameState.debugStartLevel(name)`: минуя меню, `G.gameData` для Solo, `LevelManager.loadLevel(name)`. Флаг `--start-level` → команда воркеру (T1.6).
3. `Font` и `Label` 1:1, без BitmapData: Label держит строку, шрифт, выравнивание, цвет, blend. `FrameWriter` (T1.5) выдаёт глифы как узлы с `subIndex` (texId глифа — это кадр `Font:<name>` с подпрямоугольником; расширь manifest-генератор T0.4 или добавь runtime-подтекстуры: предпочтительно в manifest по ключу `Font:<name>#<charCode>`). Побочная логика `Label.draw` (пересборка буфера при изменении текста) → в точку рендера.
4. `UISystem` и HUD-вьюхи из списка выше — 1:1 (без попапов паузы и game over: они в T2.5, `STUB(T2.5)`).
5. Сквозная проверка вручную: полёт, посадка, заправка, пассажиры, портал, конец уровня (экран завершения может быть `STUB(T2.6)` — вывести в лог «level complete»), вход P2 по W, звук.
6. e2e (`tests/e2e/level01.spec.ts`): запуск с `--start-level=Level01`, 10 с скриптового ввода (газ/влево/вправо), в консоли нет ошибок, `Frame` приходят 35/с.
