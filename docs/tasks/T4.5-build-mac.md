# T4.5 — macOS build (dmg, arm64)

**Milestone:** M4 · **Depends on:** T2.8, T3.6 · **In parallel with:** T4.6 · **Size:** S

## Goal
`npm run build:mac` produces `Alien Transporter Remaster-<ver>-arm64.dmg`. The application installs into /Applications and runs on a MacBook Pro M5 Pro.

## Steps
1. `electron-builder.yml`, mac:
   - `target: dmg`, `arch: arm64`, `category: public.app-category.games`;
   - the icon `resources/icon.icns` (`directories.buildResources = resources`), built from the game's art (e.g. `IconShuttle*` or the main screen; 1024×1024 → `iconutil`);
   - `extendInfo.NSLocalNetworkUsageDescription`;
   - `identity: null` (no Apple Developer ID), `hardenedRuntime: false`.
2. Before packaging, `npm run extract` is run if `assets/` is missing or stale (per `.cache.json`).
3. If after installation macOS says "the app is damaged" — an ad-hoc signature: `codesign --force --deep -s - "/Applications/Alien Transporter Remaster.app"` (add it as an `afterSign` hook if needed). For files downloaded from another computer: `xattr -cr <app>`.
4. Verification per `05` §10 (macOS).

## Acceptance criteria
- [ ] The dmg installs, the application launches with a double click, Retina 3x, 120 FPS, sound, saves in `~/Library/Application Support/<productName>/`.
- [ ] The Local Network prompt when hosting and joining shows our text. LAN works from the built version.
- [ ] Commit `T4.5: mac build`.
