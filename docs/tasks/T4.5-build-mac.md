# T4.5 — Сборка macOS (dmg, arm64)

**Милстоун:** M4 · **Зависит от:** T2.8, T3.6 · **Параллельно с:** T4.6 · **Размер:** S

## Цель
`npm run build:mac` выдаёт `Alien Transporter Remaster-<ver>-arm64.dmg`. Приложение ставится в /Applications и работает на MacBook Pro M5 Pro.

## Шаги
1. `electron-builder.yml`, mac:
   - `target: dmg`, `arch: arm64`, `category: public.app-category.games`;
   - иконка `resources/icon.icns` (`directories.buildResources = resources`), собранная из арта игры (например, `IconShuttle*` или главный экран; 1024×1024 → `iconutil`);
   - `extendInfo.NSLocalNetworkUsageDescription`;
   - `identity: null` (без Apple Developer ID), `hardenedRuntime: false`.
2. Перед упаковкой запускается `npm run extract`, если `assets/` отсутствует или устарел (по `.cache.json`).
3. Если после установки macOS пишет «приложение повреждено» — ad-hoc подпись: `codesign --force --deep -s - "/Applications/Alien Transporter Remaster.app"` (добавить как `afterSign`-хук, если нужно). Для файлов, скачанных с другого компьютера: `xattr -cr <app>`.
4. Проверка по `05` §10 (macOS).

## Критерии приёмки
- [ ] dmg устанавливается, приложение запускается двойным кликом, Retina 3x, 120 FPS, звук, сохранения в `~/Library/Application Support/<productName>/`.
- [ ] Запрос Local Network при хостинге и подключении показывает наш текст. LAN работает из собранной версии.
- [ ] Коммит `T4.5: mac build`.
