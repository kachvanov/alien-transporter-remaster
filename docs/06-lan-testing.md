# 06. Проверка LAN-игры (T3.7)

Как проверять сеть, результаты прогона T3.7 и пошаговая инструкция для ручной части (Mac ↔ Windows).
Чек-лист и бюджеты — `05-verification.md` §8–§9, протокол — `03-frame-and-network-protocol.md`.

## 1. Инструменты

| Что | Команда |
|---|---|
| Прокси с задержкой (TCP, обе стороны независимо, порядок байт сохраняется) | `npx tsx tools/net/latency-proxy.ts --listen 47030 --target 127.0.0.1:47020 --delay 30 --jitter 15`, клиент подключается к `127.0.0.1:47030` (UDP-анонсы через прокси не идут: адрес вводить руками) |
| Проверка хоста со второй машины без игры (TCP+WebSocket, кадры/с, КБ/с, ping) | `npx tsx tools/net/host-probe.ts 192.168.0.5 [--seconds 10]` (слот клиента занят на время проверки) |
| Размер кадров по уровням (худший случай трафика) | `npx tsx tools/net/frame-sizes.ts [11 \| 1-20]` |
| Диагностика Windows (адреса, профиль сети, правила фаервола, порт) | `powershell -ExecutionPolicy Bypass -File tools\net\windows-check.ps1 [-Peer 192.168.0.5]` |
| Счётчик трафика хоста | при уходе клиента хост пишет в stdout `[host] client left (...); sent to it: avg … KB/s, peak … KB/s` |
| Всё чек-листа на одной машине (реальные Electron-экземпляры) | `T37_RUNS=5 T37_REPORT=1 npx playwright test tests/e2e/net-verification.spec.ts` (`T37_SHOTS=<папка>` — скриншоты) |
| Экран Host: «YOUR ADDRESSES - PORT 47020», кнопка TEST | Online → Host game → TEST: подключается к каждому своему адресу и порту; `OK`/`FAIL ECONNREFUSED <ip>` |

TEST доказывает, что сервер слушает на сетевых интерфейсах, а не только на loopback. Он **не** доказывает, что фаервол
пускает чужие машины (соединение со своим адресом фаервол не фильтрует) — для этого `host-probe` / `Test-NetConnection` со второй машины.

## 2. Результаты прогона на одной машине (MacBook, два Electron-экземпляра, Level11)

Замер «задержки ввода клиента»: в странице клиента от `keydown` ArrowUp (газ) до кадра отрисовки, где появился корабль P2
(MutationObserver на `data-sprites`). Включает: опрос ввода клиентом (до 1 кадра экрана), путь до хоста, ожидание тика хоста
(0…29 мс), сам тик, кадр до клиента, задержку jitter-буфера и отрисовку. Не включает задержку ОС между нажатием и событием и
вертикальную синхронизацию монитора (+0…16 мс). Хост и клиент делят один процессор и GPU — на двух машинах джиттер меньше.

| Сценарий | Задержка ввода, мс (5 запусков) | Jitter-буфер | Underruns / dropped за 20 с | Трафик хост→клиент |
|---|---|---|---|---|
| Напрямую (127.0.0.1), буфер ≥ 1.5 тика (до правки) | 115 105 110 98 92 (медиана 105) | 1.50 тика = 43 мс | 0 / 0 | avg 95, peak 127 КБ/с |
| Напрямую, буфер ≥ 1.0 тика (итог) | 97 82 92 86 104 (медиана 92) | 1.13 тика = 32 мс | 0 / 0 | avg 94, peak 125 КБ/с |
| Через прокси 30 ± 15 мс в каждую сторону (3 запуска) | 161 152 177 (≈ +60 мс RTT) | 1.87 тика = 53 мс | 0 / 0 | avg 95, peak 120 КБ/с |

- Хост-половина пути (ws-клиент: бит газа → кадр, где P2 вошёл): медиана 41 мс (39…57).
- Автопоиск: хост виден через 280–340 мс после старта сканирования (≤ 2 с).
- Трафик по уровням (`frame-sizes`, 30 с ввода, оба игрока летят): средний кадр 3.3–6.3 КБ (113–216 КБ/с), самый большой кадр
  10.8 КБ (Level12) — даже если бы он шёл каждый тик, 368 КБ/с. Бюджет 500 КБ/с выдержан с запасом, `perMessageDeflate` не нужен.
- Jitter-буфер: нижняя граница задержки D снижена с 1.5 до 1 тика (DEVIATION, `src/app/main.ts`): на тихой сети D = 1.5 упирался
  в пол и ввод был ~105 мс; сейчас ~92. Шумная сеть поднимает D сама (D = 1 + 2σ/тик; за прокси 1.8–1.9).

Фаервол не проверялся: на этом Маке он выключен (`socketfilterfw --getglobalstate` → disabled), все прогоны — на одной машине через
loopback и TEST по LAN-адресу. Запрос macOS на доступ к локальной сети и окно Defender Firewall появляются только на реальной сборке/второй
машине — смотреть в шаге 6.

## 4. Ручной шаг 6: Mac ↔ Windows

Нужно: оба компьютера в одной Wi-Fi-сети; на Windows Java 17 и ffmpeg (для `npm run extract`), либо готовая сборка
(`npm run build:win` — T4.6) .

1. Windows (если собственной сборки ещё нет): `git clone`, `npm ci`, `npm run extract`, `npm run dev`. Положить `AlienTransporter.swf`
   как в `CLAUDE.md` (переменная `ORIGINAL_SWF`).
2. Сеть Windows должна быть **Частной**: Параметры → Сеть и Интернет → Wi-Fi → свойства сети → Профиль сети → Частные.
3. `powershell -ExecutionPolicy Bypass -File tools\net\windows-check.ps1` — смотрим адреса и профиль.
4. **Хостит Mac.** Mac: Online → Host game, записать адрес (экран показывает `ip:47020`), нажать TEST (должно быть `OK`). При первом запуске macOS
   спросит про локальную сеть — разрешить; если включён фаервол macOS — «Allow incoming connections».
   Windows: `npx tsx tools/net/host-probe.ts <ip-мака>` — ждём `result : ok`, ~35 кадров/с, ping. Затем в игре Online → Join game:
   хост должен появиться в списке за ≤ 2 с (иначе ввести адрес руками); войти, лететь газом (↑ ← →), проверить плавность и что P2 входит.
5. **Хостит Windows.** Windows: Online → Host game → при запросе Defender Firewall поставить «Частные сети» и «Разрешить доступ»; TEST → `OK`.
   Mac: `npx tsx tools/net/host-probe.ts <ip-windows>`; затем Join.
   Если `host-probe` пишет `ETIMEDOUT`/`EHOSTUNREACH`: профиль сети «Общедоступная», правило фаервола не создано (при отказе в первом окне
   его нет — Параметры → Безопасность Windows → Брандмауэр → «Разрешить работу с приложением», найти Alien Transporter / Electron),
   либо роутер включил «изоляцию клиентов Wi-Fi». Проверка с Mac: `nc -vz <ip-windows> 47020`; с Windows: `Test-NetConnection <ip-mac> -Port 47020`.
6. В каждом направлении записать: список автопоиска, `host-probe` (кадры/с, КБ/с, ping), на глаз плавность и отклик, F3 на клиенте.
   Хост при уходе клиента пишет в консоль трафик (`npm run dev` — в терминале).

## 5. Что сделано в T3.7 помимо инструментов

- `electron-builder.yml`: `mac.extendInfo.NSLocalNetworkUsageDescription` (текст из `03` §8). Для Windows ничего в сборке не нужно
  (правило фаервола создаёт сама система при первом `listen`); описание для README — в §4 (T4.7).
- Имя клиента в `hello` — `os.hostname()` (раньше было захардкожено `Player 2 (darwin)`); имя хоста в маяке уже подставляется
  в `electron/main.ts` (`sanitizeBeaconInfo`, пустое имя заменяется на `os.hostname()`).
- Тест: `DISCOVERY_PROTO` (electron/net/discovery.ts) равна `PROTO_VERSION` (src/net/protocol.ts).
